# 数据约定

稳定公共数据的格式与字段语义集中在本目录。现有四份 JSON Schema 保持字段、版本和文件身份；本轮只归位已有说明，不新增运行格式或校验体系。操作流程、命令、支持范围与验收仍由 `docs/` 和对应工具说明维护。

| 当前需要 | 唯一说明与现有机器定义 |
| --- | --- |
| 原理图意图、放置计划与现场快照 | [原理图数据](schematic.md)；[电路设计稿](schematic-contract.v1.schema.json)、[放置计划](schematic-placement-plan.v1.schema.json)、[现场快照](schematic-snapshot.v1.schema.json) |
| 原理图批次、绑定与连接输入输出 | [原理图操作](schematic-operations.md) |
| 器件资料请求、取得结果与缓存 | [器件资料](parts.md) |
| PCB 配置、标准化读取、本轮范围与布局候选 | [布局数据](pcb-layout.md)；[电气关系扩展](pcb-layout-intent.v1.schema.json) |
| PCB 新建、板框、移动、线宽与配色 | [PCB 操作](pcb-operations.md) |
| 网络规划、FR、预走线与地空间 | [走线数据](pcb-routing.md) |
| 能力发现、操作状态与回执 | [执行数据](execution.md) |
| 可选交接记录与面板解析标记 | [项目记录](project-records.md) |

## 现有说明的缺口

- 原理图放置计划和现场快照已有 JSON 结构定义，完整的软件绑定及原生观察扩展语义尚未在旧文档中逐字段说明；当前沿用现有定义和消费者，不把缺省观察解释为已核验。
- 批次、连接、重排、导线／标识／NC 等公共操作的完整计划和结果形状，部分仍只由实现与测试描述。本页所链接的说明只收拢已经写明的字段，不补造缺失的版本或对象。
- PCB 原生快照、完整布局计划、准备回执及一般候选的完整字段清单尚不齐全；布局配置和块内请求已有说明不等于上述所有对象都有完整机器定义。
- FR／预走线的完整 board、铜候选和模式专属结果，以及层叠、禁区、铺铜和接地操作的完整公共对象，还缺统一的字段正文；当前保留其已有接口和独立验收。
- runner 的完整报告／摘要、CLI 通道请求回执及面板 status 返回尚缺完整字段说明；此轮保留现有执行与测试约定，不新增协议。
- 四份 JSON Schema 没有被通用运行校验器直接加载。现有入口采用各自专用检查，仓库检查只核对部分 schema 元数据；归位不扩大其检查或工程验收范围。

项目实例、历史回执、算法内部 model／IR、维护缓存与制造／样机检查清单不迁入本目录。新增字段正文前仍需核对真实生产者、消费者和已存在的格式。
