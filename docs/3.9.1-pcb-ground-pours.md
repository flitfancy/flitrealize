# 3.9.1 实际铺铜

布局和当前关键走线已明确后，创建或更新实际参考铜，再交给 [3.9.2 回流与必要接地过孔](3.9.2-pcb-grounding.md)。

## 输入

复用实际板框、铜层、禁区、布局和走线，明确目标网络、层、铺铜边界、板边／孔／焊盘／异网间距、热焊盘或直连方式，以及需要保留的铜、过孔、开槽、分区和回流通道。制造依据来自板厂能力或明确假设；只暂停阻止当前修改或影响已有重要内容的缺口。

## 处理

1. 结合实际布局和关键路径，确认参考铜的网络、层、边界、连接方式及禁区作用，再创建或修改平面与铺铜。
2. 重新铺受影响的铜，检查实际填充、孤岛、狭窄通道、意外断开和关键净空。铺铜边界存在不能证明实际铜已生成。
3. 核对机械对象和原有内容，目检关键铜形状并检查当前规则能够识别的问题。复杂板可先核对代表层或区域；特殊几何只暂停相关区域。
4. 保存并核对本次结果。DRC 不能独立证明回流合理；布局时的潜在地空间估算也不能代替实际填充和连通检查。

实际创建、重铺、回读和局部恢复见 [3.9.1-r EasyEDA 实现](providers/easyeda-pro/3.9.1-r-pcb-ground-pours.md)，共同执行与保存判断见 [0.3](0.3-easyeda-pro.md)。

## 产物

交出已生成的实际参考铜、目标网络与层、填充和净空检查、保存结果及未决项。源设计和证据对应同一版本，尚未核对的回流条件保留明确状态。

## 进入下一步

本轮参考铜已实际生成，关键孤岛、断开和净空问题已处理，PCB 已保存且没有未解释的当前 DRC 问题后，进入 [3.9.2](3.9.2-pcb-grounding.md)。
