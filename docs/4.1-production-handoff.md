# 4.1 制造文件与原型下单

从已保存并完成本次检查的 PCB，准备与源设计对应的制造包。流程为确定候选 → 导出并检查文件 → 核对厂商解释与预览 → 保存候选和交接。按本次裸板、PCBA 或下单范围执行。

## 确定本次候选

确认对应原理图、PCB、BOM 与板卡版本，当前检查状态和已接受的原型限制；明确裸板／PCBA、数量、装配变体，以及层数、板厚、铜厚和特殊制造要求。源设计仍在变化时，保存后再从同一版本导出，不能混用不同版本文件。

候选身份、源文件、制造参数、文件清单与检查结果只在本次制造包的已有导出清单或候选记录中集中保存。可沿用 `manufacturing/<candidate-id>/manifest.md` 和裸板／PCBA 子目录；不要求再建第二份同义记录。

## 导出并检查文件

### 裸板

导出 Gerber、PTH／NPTH 钻孔、槽孔／铣边、板框和必要制造说明。检查层用途、闭合板框与尺寸、孔槽、顶底方向、最新铺铜、阻焊／钢网／盖油，以及线宽、间距、孔径和板边要求；排除旧版本、多余板框或废弃图层。文件存在或数量齐全不证明内容正确。

### PCBA

另备受控 BOM、CPL／贴片坐标、DNP、装配变体、顶底面、极性／pin 1 和必要装配说明。

BOM 核对位号、数量、数值／作用、准确制造商型号或完整通用规格、封装、采购身份、DNP 与允许替代范围。CPL 与 BOM 对账，检查坐标、原点、顶底面、旋转及极性／非对称器件方向。本次实际料号从已接受器件或替代范围中选择，不在下单时临时建立电气等价关系。

## 核对厂商解释与预览

文件检查确认导出的内容；厂商预览确认对方怎样解释这些内容。核对板框、尺寸、层、孔槽、铜、阻焊和丝印；PCBA 另查器件缺失、装配面、旋转、极性和 pin 1，以及 DFM 提示或自动修改。

差异回到源设计、导出设置或厂商解释中对应的一侧处理。自动识别、替代或修正没有依据时保持待确认。预览或等效检查尚未完成的范围明确保留。

## 保存候选与交接

候选记录引用同一版本的源文件、Gerber、钻孔、BOM、CPL、检查与厂商预览，保留已接受限制和样机验证项。设计变化后形成新候选，不静默覆盖已接受文件。

按[0.1](0.1-continuation.md#信息归属与更新)更新制造章节和顶部交接：写当前结论、遗留项、下单状态及候选入口，引用上述唯一记录，不重抄制造包字段。准备完成时，本次所需文件、内容检查、预览和实际料号都能对应到该候选。

## 原型下单

下单前比较订单与已检查候选：数量、板厚／铜厚、表面处理、颜色、特殊工艺；PCBA 的器件／替代、DNP、装配面和数量；报价或缺货变化，以及收货后的上电测试安排。新增差异先核对，未审核器件不能随报价替换自动接受。

生成和检查文件按已授权范围执行。提交订单、付款、预留或扣减库存是本次外部承诺，授权沿[主 Skill](../SKILL.md#任务范围)。开始上电和样机验证时再进入[5.1](5.1-prototype-validation.md)。
