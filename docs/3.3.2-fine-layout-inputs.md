# 3.3.2 块内布局输入与转置

把本轮局部调整范围及电气要求，转成基于真实焊盘和外部环境的约束、目标与验收条件，供块内布局使用。

## 拿到什么

复用 [3.3](3.3-pcb-layout-inputs.md) 的共同输入，并取得：

- 功能块布局或人工确认的大致区域和整体安排。
- 所选功能块的完整成员，以及已有簇和局部关系。
- 实际焊盘、网络、跨块端点及相关电气要求。
- 本轮固定件、可移动和可旋转器件、位号权限及允许让位的邻居。
- 当前区域、外部障碍、装配与预留条件。
- 本轮比较目标、验收要求和计算预算。

功能块归属不自动生成区域硬边界，主器件也不因名称默认固定。

## 怎么转置

### 明确调整范围

先从完整功能块成员确定本轮范围，再说明哪些参与、哪些固定或排除，以及原因。仅调整部分成员时明确记录，不能把缩小后的名单当作完整功能块。

修改范围和检查范围分别确定。范围外真实障碍、相关焊盘和跨块连接继续保留；邻居只有在明确允许时才参与让位。

### 选择电气指标

根据具体要求确定作用对象、计算口径和用途：

- 指定引脚之间的靠近关系，使用明确的端点距离。
- 网络分散程度，使用适用的网络跨度指标。
- 整组最坏项、支路配合或主次取舍，先明确关系集合和判断方法，再核对公共入口是否支持。

每项分别声明是硬条件、优化目标还是观察指标。没有依据时不编造数值上限，也不把用途名称直接当成完整计算规则。

当前支持范围统一见[电气要求与规则转置](../schemas/pcb-layout.md#电气要求与规则转置)。尚未接通的指标不能因写进文字就视为已参与求解。

### 合成基础与本轮规则

引用已有关系的稳定 ID，复用端点、网络及依据。按本轮需要继承、替换或追加软目标，避免同一要求重复计分；替换软目标不删除基础硬条件。

本轮非退化要求使用明确的比较基线，不把所有旧距离自动当作安全上限。已有问题和现场变化按 [0.3](0.3-easyeda-pro.md)处理。

### 加入几何与位号条件

使用块内布局自己的间距和装配要求，明确工作区域、预留用途、锁定来源及位号规则，不继承功能块阶段的默认间距。

电气、几何和位号条件共同作用于本轮候选，但各自保留计算口径和验收结果。

## 交出什么

交出块内布局有效输入，说明：

- 完整块成员、本轮参与成员、未参与成员及原因。
- 本轮区域、固定条件、邻居和位号权限。
- 已绑定的真实端点、外部环境和跨块关系。
- 每项有效约束、优化目标、观察指标及来源。
- 继承、替换、追加和本轮验收条件。
- 来源版本、预算、未覆盖项及诊断。

影响本轮计算与验收的必要条件明确后，交给 [3.5.2 块内布局](3.5.2-fine-layout.md)。明确要求但入口尚不支持时，指出具体缺口，不静默忽略或另换指标。

字段与合成规则见[布局数据约定](../schemas/pcb-layout.md#块内布局输入与权限)，命令、候选接入及执行范围见[块内布局执行接口](technical/pcb-fine-layout-execution.md)。
