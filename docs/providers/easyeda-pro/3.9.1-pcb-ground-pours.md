# 3.9.1 EasyEDA Pro 创建、重铺并检查实际铜

布局和当前关键走线已明确，需要创建或更新实际参考铜时读取。板框、层叠和功能性禁布区的前期落实见 [3.2](3.2-pcb-foundation.md)；完成实际铜后进入 [3.9.2 回流检查](3.9.2-pcb-grounding.md)。

布局阶段按需使用的[潜在地空间诊断](../../technical/pcb-ground-space.md)只估算候选空间，不创建铜，也不能代替本页的实际填充与连通检查。

## 确认当前输入

共同目标与执行规则见 [0.3](../../0.3-easyeda-pro.md)；本次还需明确：

- 已有板框、铜层、功能性禁布区与当前布局和走线；
- 需要创建或保留的平面与铺铜网络、目标层和边界；
- 板边、孔、焊盘和其他网络的间距，热焊盘或直连方式；
- 需要保留的已有铜、过孔、开槽、分区和回流通道；
- 当前板厂能力或本阶段采用的明确假设。

只有缺口让当前修改无法落地，或可能覆盖已有重要内容时，才停止受影响操作；其余工作可以继续。

## 使用现有操作

- `pcb-ground-pours`：读取和修改有边界的参考铜。

实际能力以当前操作清单、能力探测和运行结果为准。现有操作不能完成的局部操作，可以使用 EasyEDA 当前可用的方法完成，并在写入后回读验证。

## 1. 读取当前实际对象

修改前读取目标层、板框、禁布区、当前走线和过孔，以及需要保留的 Region、铺铜边界与实际铜。核对网络、对象身份和保存状态；画布外观不能代替实际对象回读。

## 2. 创建或修改参考铜

布局和关键布线完成后再执行本节，使实际铜形状和回流通道能够结合真实几何检查。

板框和功能性禁布区清楚后，创建当前设计需要的平面或铺铜。

确认：

- 目标网络；
- 所在层；
- 铺铜边界；
- 与板边、孔、焊盘和其他网络的间距；
- 禁布区是否实际生效；
- 热焊盘或直连方式；
- 需要保留的开槽、分区和回流通道。

铺铜边界存在不代表铜已经成功生成。创建或修改后必须重新铺铜，并检查实际填充、孤岛、狭窄通道、意外断开以及关键区域的净空。

复杂板卡可以先在一个代表层或区域完成检查，再扩展到其他层。某个特殊几何无法解析时，只暂停受影响区域，不把未相关的整块 PCB 一起阻塞。

## 3. 重铺、检查并保存

完成当前参考铜增量后：

1. 重新铺受影响的铜；
2. 回读新增或修改的 Region、铺铜和对应层；
3. 检查板框、机械对象和原有内容是否保持；
4. 目检关键禁布区和实际铜形状；
5. 运行当前项目配置的 DRC；
6. 保存 PCB；
7. 确认保存后的文档仍包含本次结果。

DRC 只能检查当前规则能够识别的问题。参考铜是否为关键网络提供了合理回流，还需要结合实际布局和布线判断，见 [3.9.2](3.9.2-pcb-grounding.md)。

## 失败与恢复

按 [0.3 EasyEDA Pro 软件适配层](../../0.3-easyeda-pro.md) 重新读取现场后再处理。参考铜恢复只补齐或撤销本次能够准确识别的 Region 和铺铜对象，保留范围外内容。

## 完成本阶段

完成本次参考铜处理后确认：

- 需要的参考铜已经实际生成；
- 关键区域没有明显孤岛、断开或错误净空；
- PCB 已保存且没有未解释的当前 DRC 问题。

随后读取 [3.9.2 回流检查与必要接地过孔](3.9.2-pcb-grounding.md)。
