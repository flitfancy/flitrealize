# 3.9.2-r EasyEDA Pro 回流检查与必要接地过孔

工程判断、地孔用途和交接见 [3.9.2](../../3.9.2-pcb-grounding.md)。本页维护原生检查、补孔和局部恢复；共同现场执行按 [0.3](../../0.3-easyeda-pro.md)。

## 操作与范围

- `pcb-grounding-inspect` 读取铺铜、Region、过孔及相关器件。
- `pcb-ground-vias` 规划、写入和验证范围明确的地孔。
- `pcb-ground-stitching` 为换层回流、平面连接或板边屏蔽生成候选。

按清单、能力探测和回执核对覆盖对象。规划候选与实际写入、回读分别记录；自动化不覆盖的局部几何按当前原生能力处理并说明未覆盖范围。

## 原生回读与补孔

读取实际铜、走线、换层、已有孔及本次目标网络和对象。仅应用经过工程筛选的孔位，按实际对象 ID 或准确几何回读新增孔，核对网络、位置、尺寸和数量，确认原有孔保持。

增加或移动孔后重铺受影响的铜，读取实际连接，检查是否产生孤岛、细颈或间距问题；结合关键区域目检与当前 DRC 沿公共链保存、回读。第一次创建成功不代表地孔已连接有效铜或回流已通过。

## 局部恢复与返回

按 0.3 对账，只补齐或撤销准确识别的本次孔及相关铜对象，不复用过期坐标。无法自动判断的特殊几何只暂停相关区域，使用实际回读或人工检查，不把未知连通标为通过。

交出原生对象、连接、重铺、DRC 与保存结果，返回 [3.9.2 交接](../../3.9.2-pcb-grounding.md#进入下一步)。
