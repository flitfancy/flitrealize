# 3.2 EasyEDA Pro 板框、层叠与禁区

本轮板框、层叠和功能性禁布区方案已明确，需要在 EasyEDA Pro 落实或修改时读取。整体方案变更才按需查 [3.1](../../3.1-pcb-review.md)。

本流程在布局前落实物理边界与禁区。走线后的实际参考铜见 [3.9.1](3.9.1-pcb-ground-pours.md)，回流和必要接地过孔见 [3.9.2](3.9.2-pcb-grounding.md)。逻辑参考层或平面网络设置不表示已经创建实际铜。

## 确认当前输入

共同目标与执行规则见 [0.3](../../0.3-easyeda-pro.md)；本次还需明确：

- 当前板框、安装孔和机械接口；
- 已选择的铜层数量及每层作用；
- 重要信号使用的参考层；
- 需要落实的功能性禁布区；
- 已有布局、布线、过孔和铺铜中需要保留的内容；
- 当前板厂能力或本阶段采用的明确假设。

适用项可以是已确认、暂定或明确不适用。只有缺口会让当前修改无法落地，或可能覆盖已有重要内容时，才停止受影响操作；其余工作可以继续。

## 使用现有操作

当前相关操作包括：

- `pcb-layer-stack`：读取和修改逻辑铜层结构；
- `pcb-component-geometry`：读取器件、焊盘和封装几何；
- `pcb-functional-keepouts`：读取和修改有明确用途的禁布区。

实际能力以当前操作清单、能力探测和运行结果为准。现有操作不能完成的局部操作，可以使用 EasyEDA 当前可用的方法完成，并在写入后回读验证。

## 1. 读取当前 PCB

修改前读取与本次工作有关的实际对象：

- 板框和开槽；
- 铜层及顺序；
- 器件、焊盘和安装孔；
- 已有走线、过孔和平面；
- 禁布区和其他 Region；
- 当前保存状态。

画布外观可以帮助理解，但不能代替对象身份、层、网络和几何回读。

如果 PCB 已经存在手工布局或布线，先确认本次修改会影响哪些对象，不通过重新生成整个基础结构覆盖已有工作。

## 2. 建立层和板框

按照项目已确认的方案设置：

- 铜层数量和顺序；
- 每层主要作用；
- 参考层和平面网络；
- 板框、槽和必要机械边界；
- 安装孔和边缘接口位置。

逻辑层名称或平面网络设置不能证明实际铜已经存在。物理介质厚度、铜厚和阻抗参数仍应来自当前板厂能力或项目假设。

增加层通常可以作为局部修改处理。减少层、改变已有层用途，或移动已经承载铜和器件的板框，可能删除或破坏现有内容；发现这种实际冲突时，先确认受影响对象和处理方法，再继续执行。

写入后回读层顺序、板框和关键机械对象，确认没有意外移除已有内容。

### 矩形板框（可执行入口）

```text
node <skill>/scripts/action-runner.mjs list --domain pcb --query "板框"
```

操作：`pcb-board-outline`。必须使用 `pcb_PrimitivePolyline.create` + `pcb_MathPolygon.createPolygon` 写 **layer 11**；`pcb_PrimitiveLine.create` 不能创建板框折线。

矩形输入、单位与替换字段见[板框数据约定](../../../schemas/pcb-operations.md#矩形板框输入)。执行仍沿 plan → apply → verify → save。

## 3. 落实功能性禁布区

只为明确的工程目的创建禁布区，例如：

- 天线净空；
- 麦克风、压力、光学或气流开口；
- 电气隔离；
- 安装和机械活动空间；
- 厂商明确规定的禁铜区域；
- 需要限制器件、走线、过孔或铺铜的区域。

为每个禁布区明确：

- 作用；
- 来源；
- 几何边界；
- 影响的层和对象类型；
- 是否允许必要的局部例外。

丝印外框、庭院层或视觉空白不自动等于铜禁布区。需要从实际器件、封装或机械几何确认边界。

写入后回读新增 Region 的层、规则和几何，并检查它没有覆盖焊盘、板框、必要走线或其他受保护对象。

## 4. 检查并保存

完成当前基础增量后：

1. 回读新增或修改的层、板框和 Region；
2. 检查板框、机械对象和原有内容是否保持；
3. 目检关键禁布区的层、规则和几何；
4. 若本次修改影响已有铺铜，重铺并核对受影响的铜；
5. 运行当前项目配置的 DRC；
6. 保存 PCB；
7. 确认保存后的文档仍包含本次结果。

维护已有铜不表示布局前创建新的参考铜。创建、重铺和实际铜检查集中在走线后的 [3.9.1](3.9.1-pcb-ground-pours.md)。

## 失败与恢复

按 [0.3 EasyEDA Pro 软件适配层](../../0.3-easyeda-pro.md) 重新读取现场后再处理。基础恢复只补齐或撤销本次能够准确识别的层、板框和 Region；涉及已有铜时核对受影响内容，不覆盖范围外对象。

## 完成本阶段

返回 3.1 继续布局前确认：

- 铜层顺序和作用与当前设计一致；
- 板框、安装孔和主要机械接口正确；
- 功能性禁布区已经落实并回读；
- 本次修改已检查、保存，原有内容保持。

进入 [3.3 布局输入与规则转置](../../3.3-pcb-layout-inputs.md)，继续功能块布局与块内布局。
