# 3.4 PCB 网络配色

检查、预览或修改当前 PCB 网络配色时读取。用户所说“焊盘着色”在本入口采用net-class网络配色辅助识别；不直接修改每个焊盘颜色。共同目标与执行规则见 [0.3](../../0.3-easyeda-pro.md)。已有规则从 [3.6](3.6-pcb-routing-plan.md)生成 `colorPlanRequest`，仅配色可直接提供本页输入。

## 布局前的配色顺序

检查并按既定规则设置网络配色是 [3.3 布局输入与规则转置](../../3.3-pcb-layout-inputs.md)的必做项。已有配色符合规则则保留，需要补充或纠正时按规则设置。配色用于辅助辨识；连接正确性仍由原理图、实际 PCB 与网表回读核对。按下列顺序检查并记录结果，无法执行的部分明确原因与未完成状态。

1. 核对本次PCB目标及实际网名清单，复用项目已有的网络规则配置；不从待检查的分类反向生成网名。
2. 核对类、成员、已确认用途与现场配色，符合既定规则且仍一致时保留，不每轮布局重新分类或改色。需要补充时，从项目已经确认的电路设计稿／接口用途／网络规则取得 `kind` 或已接受的显式色值，不按网络名称猜用途。
3. 只处理本次用途明确的完整类。未知类别保持EDA现有/默认显示并标未决，不虚构kind或色值；规划只选择已确认的类，其余网不参与着色写入。类缺失或成员冲突时报告对应缺口，现入口不自动创建分类。
4. 检查现有配色或完成改色后，取得颜色回读并查看当前画布，确认实际可见效果；执行改色时核对保存与回读状态。色值回读与“焊盘已按功能显示”分开记录；显示范围与开关能力按本页边界核验。后续布局/预走线仍使用最新实际 PCB。
5. 无法完成某一步时，报告原因、受影响范围和未完成项；部分完成不能标为全部完成。

纯离线计算、只读 prepare/solve 或仅查看任务不附带 `--apply` 或其他 EDA 写入；无法核验现场或执行设置时，按上述顺序记录未完成项。配色必做要求不扩大本次授权。

## 输入与调用

项目决定网络类、完整成员和用途。脚本按固定 `kind` 色表或显式 `color` 执行，不推断用途、不创建或拆分类别。

配色请求、成员与颜色字段见[配色数据约定](../../../schemas/pcb-operations.md#网络配色输入)。

```text
node <skill>/scripts/pcb-edit.mjs --action pcb-net-color --project-root <项目> --window-id <窗口> --input-file <输入.json>
```

默认只预览 EDA，并保存本地计划和报告；加 `--apply` 才执行并保存。结果位于 `evidence/pcb-edit/<运行目录>/result.json`。

直接调用操作时，`inspect` 读取类和色表，`plan` 返回冻结成员及颜色的 `applyRequest`，`apply` 执行并回读，`save: true` 才保存。写入使用 `--allow-write`。本操作不提供独立 verify/save 或 `--resume-save`。

计划、执行结果与用途色表统一见[配色数据约定](../../../schemas/pcb-operations.md#网络配色输出与色表)。

## 执行与失败

当前实现通过重建网络类改色，保留原成员并恢复受影响的规则。写入 alpha=255，回读为 1；首个写入前、每类写入后及保存后核对网络类和规则。它不清除历史单网络颜色覆盖，也不修改布线几何。

失败保留原类、规则和已尝试范围，不自动重试或回滚。未知结果按 [软件适配层恢复](../../0.3-easyeda-pro.md#失败与恢复)对账；中断若留下缺失类，先 inspect 并对照原报告恢复。

本操作保存字段的含义见[执行数据约定](../../../schemas/execution.md#网络配色保存字段)。

颜色回读不代表画布效果已确认，结果保留 `visualVerified:false`。现入口改变已有net-class的色值，不控制显示开关，也不提供每pad直接赋色接口；历史单网覆盖、层显示、背景与缩放都可能影响识别。未完成当前画布核验时记录“颜色已回读，显示待确认”，不宣称每个焊盘已着色。缺少建类或显示控制的封装时，按当前原生能力处理并说明范围，不能绕过分类/成员检查。

离线布局SVG/候选预览目前使用固定焊盘色，尚未继承现场NetClass配色。现场颜色与候选渲染是两个接口，不能从离线图推断实际焊盘已按功能显示；把分类颜色贯穿候选报告仍是后续衔接缺口。

## 项目记录

在主文稿“网络规则”的配色小节记录分类来源、范围、kind／显式色值、配色检查、保留或设置、保存回读及视觉确认结果；无法完成的部分记录具体原因、范围和未完成状态。按 [0.1](../../0.1-continuation.md#pcb-主题与面板对应)更新相应表格行、`ViewState:` 和顶部交接。颜色来自实际计划或回读，未知用“—”；完整成员及证据留在配置和报告。
