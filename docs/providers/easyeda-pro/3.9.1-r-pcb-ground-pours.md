# 3.9.1-r EasyEDA Pro 创建、重铺并检查实际铜

工程输入、实际铜检查和交接见 [3.9.1](../../3.9.1-pcb-ground-pours.md)。本页维护原生对象操作，目标、写入、保存和未知结果判断按 [0.3](../../0.3-easyeda-pro.md)。

## 操作与范围

`pcb-ground-pours` 读取和修改有边界的参考铜。按当前操作清单、能力探测和实际回执确认支持范围；不能完成的局部几何使用当前可用的 EasyEDA 方法并核验，不把边界对象当作已填充铜。

## 读取、创建与重铺

操作前读取目标层、板框、禁区、走线、过孔及需保留的 Region、铺铜边界和实际铜，核对对象身份、网络和保存状态。按已确定的网络、层、边界及连接规则创建或修改参考铜，再重新铺受影响的铜。

回读新增或修改的 Region、铺铜及对应层，检查原有机械对象与范围外内容；目检实际填充和关键净空，运行当前配置 DRC，并沿公共执行链保存和核对结果。实际回流由后续 [3.9.2](../../3.9.2-pcb-grounding.md)验收。

## 局部恢复与返回

按 0.3 对账，只补齐或撤销准确识别的本次 Region 和铺铜对象，保留范围外内容。交出原生对象、重铺检查及保存证据，返回 [3.9.1 交接](../../3.9.1-pcb-ground-pours.md#进入下一步)。
