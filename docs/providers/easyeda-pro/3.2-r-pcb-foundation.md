# 3.2-r EasyEDA Pro 板框、层叠与禁区

工程输入、处理和交接见 [3.2](../../3.2-pcb-foundation.md)。本页维护实际读取、原生操作和局部恢复；共同目标、写入与保存判断按 [0.3](../../0.3-easyeda-pro.md)。

## 操作与范围

- `pcb-layer-stack` 读取和修改逻辑铜层结构。
- `pcb-component-geometry` 读取器件、焊盘和封装几何。
- `pcb-functional-keepouts` 读取和修改有明确用途的禁区。
- `pcb-board-outline` 创建或替换受支持的矩形板框。

调用前按能力清单核对支持范围，已有操作不能完成的局部部分使用当前可用的 EasyEDA 方法并回读核验，不据操作名称推断覆盖全部几何。

## 读取与原生修改

读取板框与槽、铜层及顺序、器件／焊盘／安装孔、走线／过孔／平面、禁区及其他 Region 和保存状态。已有手工内容的修改范围由实际对象确认。

矩形板框入口：

```text
node <skill>/scripts/action-runner.mjs list --domain pcb --query "板框"
```

`pcb-board-outline` 使用 `pcb_PrimitivePolyline.create` 和 `pcb_MathPolygon.createPolygon` 写 **layer 11**；`pcb_PrimitiveLine.create` 不能创建板框折线。矩形输入、单位和替换字段见[板框数据约定](../../../schemas/pcb-operations.md#矩形板框输入)。

层与板框修改后回读顺序、边界和关键机械对象；新增 Region 核对层、规则和几何，并确认没有覆盖焊盘、必要走线或其他受保护对象。涉及已有铜时重铺并核对受影响部分，实际铜操作见 [3.9.1-r](3.9.1-r-pcb-ground-pours.md)。本次适用 DRC、保存及保存后核对沿公共执行链完成。

## 局部恢复与返回

恢复按 0.3 对账，只补齐或撤销能准确识别的本次层、板框和 Region；涉及已有铜时保留范围外内容。交出原生对象回读、检查和保存结果，返回 [3.2 交接](../../3.2-pcb-foundation.md#进入下一步)。
