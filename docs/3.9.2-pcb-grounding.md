# 3.9.2 回流与必要接地过孔

拿到 [3.9.1](3.9.1-pcb-ground-pours.md)生成的实际铜和当前走线，闭合本轮需要的电流与信号回路。地孔数量、规则网格和板边围栏本身不是目标。

## 输入

复用实际参考铜、布局、走线、换层与过孔，明确目标接地网络、孔尺寸、制造间距、板框和禁区，以及待检查的功率、敏感信号、ESD、散热或屏蔽区域。布线仍会大范围变化时先完成相关关键路径；没有实际信号路径时不提前生成大量推测性地孔。

## 处理

1. 检查去耦、开关电源和功率回路、裸露焊盘与散热、ESD／接口泄放、换层参考、高速／时钟／模拟连续参考，以及槽、禁区、平面分割和细颈造成的绕行。说明电流从哪里出发、经过什么负载、怎样返回；同名 GND 或附近有孔不能证明铜连续或回流有效。
2. 只为明确的局部回路、换层参考、散热、保护、机壳地或屏蔽目的补孔。核对实际网络、锚点、目标层可连接铜、铜与钻孔间距、孔径／外径及板厂能力，并检查焊接、钢网、返修和机械影响。靠近器件不自动证明必要；无目标铜、被禁区隔断或落在孤岛的孔不能闭合回流。
3. 重新铺受影响的铜，确认孔实际连接目标铜、回流有所改善，并检查孤岛、细颈、间距和当前 DRC；目检关键区域后保存并回读。对象创建成功与回流问题解决分别判断。
4. 必要局部回流完成后，按设计需要考虑平面互连、参考补强、RF／EMC 围栏、特定接口或换层附加回流、散热及电流分布。明确目的和停止条件，筛选有实际改善的候选；不默认铺满地孔网格，也不缩小间距或绕过禁区填充。

布局与预走线阶段的潜在地空间仅用于比较，不代替本阶段实际铜和回流验收。特殊几何只暂停相关区域；制造间距、连通、禁区或目标铜未确认时仍在 PCB 阶段处理，只有依赖实物行为的功能问题转为样机验证。

软件检查、补孔、重铺与局部恢复见 [3.9.2-r EasyEDA 实现](providers/easyeda-pro/3.9.2-r-pcb-grounding.md)，共同执行与保存判断见 [0.3](0.3-easyeda-pro.md)。

## 产物

交出本轮实际回流检查、必要地孔及用途、更新后的铜、DRC 和保存结果，以及未决区域和已接受限制；证据对应当前源版本。

## 进入下一步

必要功率／去耦回路、换层参考及 ESD、散热和屏蔽关系满足本轮要求，新增孔实际连接目标铜，铺铜已更新且没有未解释的当前 DRC 问题、PCB 已保存后，进入[整板检查](3.1-pcb-review.md#完成本阶段)，再交给 [4.1 制造准备](4.1-production-handoff.md)。
