# 3.3.1 功能块布局输入与转置

根据电路设计稿中的功能分组和电气拓扑，整理各功能块之间的关系，再结合器件尺寸、板框和机械条件，形成用于安排整体分布的布局输入。

## 一、拿到什么

复用 [3.3 布局输入与规则转置](3.3-pcb-layout-inputs.md) 的共同输入：

- 各功能块的用途、完整器件成员及真实封装尺寸。
- 设计稿中的块间连接、上下游关系、分支与汇合关系，以及明确的靠近、隔离和关键路径要求。
- 板框、固定件、接口位置与方向、禁区和装配要求。
- 影响连接空间的端点分布、连接数量、线宽需求及预留用途。
- 本轮参与范围、允许姿态和计算预算。

成员与连接关系沿用设计来源，不凭当前摆放距离重新划分功能块，也不要求先划分块内簇。

## 二、怎么转置

### 整理块间布局关系

从设计稿中明确各块承担什么功能、与哪些块连接，以及这些关系对整体分布有什么要求。结合已确认的电气条件，整理需要相邻、隔离、面向接口或为主要连接留出空间的关系，并保留依据。

上下游、分支和汇合关系用于理解整体安排，不直接规定各块必须从左到右排列。有连接也不自动意味着必须紧贴；具体位置由功能块布局结合板框和机械条件确定。

### 准备空间与连接条件

根据各块完整成员、器件尺寸和必要间距，整理估计占位所需的数据。固定接口和机械锚点保留实际位置，其余器件按本轮权限大致展开，不把已有内部摆法锁成刚性模板。

根据跨块连接的实际端点和接口，整理主要连接方向及所需空间。连接集中或需要较宽线路的一侧，应为后续出线和块间连接留出余地。具体连接侧随候选位置与允许朝向确定，已有固定方向继续遵守。

本阶段只准备整体空间与连接条件，不要求生成具体线段、逐脚出口或过孔方案。

### 形成辅助比较关系

沿用已确认的功能和连接关系，用相关器件的中心直线距离辅助比较候选：块内关系帮助成员适度收拢，跨块关系帮助相关功能块合理分布。

中心距离与空间占用、连接方向和留白一起考虑，不以总距离最短代替设计稿中的功能逻辑。相同关系避免重复计分，不生成所有器件之间的相互吸引，也不因共享地把整板聚拢。

一般距离比较不使用焊盘级距离；已有明确且适用于本阶段的电气硬要求仍保留。

### 加入本轮限制

采用功能块布局独立、可配置的间距设置，并保留板框、固定件、禁区及已有更严格的装配要求。该阶段默认间距不自动成为块内布局的间距设置。

区分必须遵守的条件与用于比较候选的偏好。临时分区、试排位置和通道预留保留本轮用途，不自动写成长期禁区或不可调整的边界。已有问题与本轮变化按 [0.3 共同执行规则](0.3-easyeda-pro.md)处理。

## 三、交出什么

转置结果沿用公共布局输入格式，交给功能块布局使用，包含：

- **分组与几何：**完整功能块及成员、本轮参与成员和排除原因，关联真实器件尺寸、固定状态与允许姿态。
- **连接关系：**从设计稿和实际网表派生参与比较的器件关系，标明块内或跨块关系，以器件中心直线距离辅助比较。
- **摆放条件：**板框、固定接口、禁区、装配间距，以及有依据的靠近、隔离和方向要求，分别转成硬限制或布局偏好。
- **空间需求：**关联需要预留空间的器件、连接侧或跨块连接，说明留白用途及数值依据。
- **执行信息：**来源版本、本轮范围、计算预算和未覆盖项。

每项转置保留来源、作用对象、计算口径，以及它是硬限制、优化目标还是检查项。字段定义与求解、验收的消费位置统一在数据约定和技术参考中维护，不要求每轮重新填写。

上下游、分支和汇合等拓扑关系用于确定上述连接与摆放条件；没有具体依据时，不自动转成固定方向或距离上限。当前入口无法表达的要求列为未覆盖项，不静默丢弃或当作已经参与计算。

[3.5.1 功能块布局](3.5.1-block-layout.md)据此生成各块的大致位置、朝向、占用空间和主要连接侧，并说明块间通道预留，供块内布局及后续走线继续使用。

## 执行说明

共用字段见[布局数据约定](../schemas/pcb-layout.md)，中心取点、关系选取、数值近似及当前支持范围见[功能块阶段技术参考](technical/pcb-layout-inputs.md#功能块阶段的求解评分与验收)。

要求是否已参与计算，以实际转置结果为准；尚未支持的内容明确列出，不因写入说明就视为已执行。
