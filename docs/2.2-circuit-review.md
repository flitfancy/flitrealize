# 2.2 电路设计校核

原理图设计与实现完成后，核对器件能力、电路分工和系统行为，确认方案满足实际需求，并说明余量、冗余和可简化之处，再交给 PCB 阶段。

首次校核覆盖本次设计的全部功能块和功能器件；已有结论按对应版本复用，后续修改只复核受影响部分及其关联关系。共同执行与已有问题按 [0.3](0.3-easyeda-pro.md)处理。

## 拿到什么

复用 [2.1 原理图设计与电路设计稿](2.1-schematic-contract.md)交出的资料：

- 当前需求、功能块和工作条件。
- 电路设计稿、对应的已保存原理图及实际连接核对结果。
- 准确器件型号、数据手册、配置和必要的固件依赖。
- 关键计算、设计余量、取舍依据及未决项。
- 结构检查、网表核对和 DRC 结果。

结构检查和 DRC 通过不能代替本页的能力与电路校核。

## 器件能力与电路分工

电路形成后，按功能块和器件清单逐一核对芯片及其他功能器件，结合外围电路检查：

- 主要功能、可配置模式和内置保护，以及对应的生效条件、参数范围和限制；
- 当前连接与配置实际使用了哪些能力，是否满足需求；
- 未使用能力的原因，是否能替代已有外围功能；
- 器件之间是否重复实现同一功能，或仍有未覆盖的需求；
- 当前方案是否产生不必要的成本、功耗、面积或复杂度。

每个功能器件保留简短对照：准确型号与资料依据、可用能力及条件、实际连接和配置、使用状态、检查结论和必要动作。检查覆盖全部相关器件，不只挑选几颗显眼的器件。

同型号资料可以复用，各实例的用途和配置分别核对。普通配套阻容随所属电路检查用途与参数，不单独展开能力清单。未确认的内容注明缺项；不能仅凭手册列有某项功能，就认为当前电路已经具备该能力。

对照结果放在主文稿相关功能块中，不另建重复记录，也不抄录整本手册或全部寄存器。后续只更新受器件、连接或配置变化影响的部分。

## 余量、冗余与简化

允许有依据的余量和冗余。额外保护、监测或备用功能应说明：

- 应对什么使用条件或风险；
- 带来什么收益；
- 增加哪些器件、成本、功耗、面积或复杂度；
- 删减后会失去什么。

按功能说明取舍，不要求每颗阻容单独审批。闲置能力本身不算浪费，重复功能也可能承担独立保护；是否保留取决于实际收益和代价。

必要安全要求继续满足。没有需求或风险依据的增强项作为可选建议，不自行扩大项目要求。简化已有设计时，说明收益、代价和适用条件，接受后再修改。

## 电路与系统行为

结合资料与计算，核对拓扑、额定值、接口电平、电源域、启动顺序、默认状态、保护行为及固件配合。检查器件间相互影响和跨块路径，确认组合后的电路满足需求。

已确认结论、设计假设和待测项分别记录。影响本次器件、连接或工作方式的缺口先处理；留到样机验证的问题明确测试条件、预期结果和判断方法。

## 交出什么

在[项目主文稿](0.1-continuation.md#信息归属与更新)的相关功能块中保存校核结论，说明：

- 本次应检查的功能块和功能器件，以及已检查、复用既有结论和未检查的对象；未检查项说明原因。
- 各功能器件的能力与实际使用对照，以及电路和跨块行为的检查结论。
- 必要余量、冗余和可简化项的依据、收益与代价，以及已接受的取舍。
- 已确认问题、设计假设、待测项和必要动作。
- 对应电路设计稿、已保存原理图版本及资料依据。

完整检查清单与结论保留在项目记录中，聊天汇报重点问题和取舍。未检查或证据不足的项目不能标为通过。

## 交给 PCB 前

汇总本次范围的设计校核、实现核对、DRC 和保存结果，确认需要转入 PCB 的功能块已经实现，关键事实与已保存原理图一致。相关 DRC 问题按 0.3 判断，保留问题的依据及影响明确。

会改变本次器件、引脚、电源结构或保护行为的问题先返回 [2.1](2.1-schematic-contract.md)处理；修改后核对受影响的实现和校核结论。不影响本次实现的未决项可以保留，并说明影响、测试条件和判断方法。

## 向 PCB 传递什么

交出当前电路设计稿、对应原理图与保存状态、设计校核结论、相关电气要求及剩余未决项。

电气内容包括功能块、器件与引脚网络、接口、电源关系，以及影响布局和走线的要求。去耦、采样、功率路径等关系说明服务对象、端点、网络和依据；器件用途本身不产生距离数值。

要求与来源留在电路设计稿和设计计算中；必要布局字段见[布局输入参考](technical/pcb-layout-inputs.md)。接口侧别、安装空间与装配要求归项目 PCB 配置，实际位置和焊盘几何由 PCB 回读取得。布局中新确认的电气决定补回电路设计稿，并复核受影响的校核结论。

本次校核完成并满足上述条件后，进入[转 PCB 并核对](3.1-pcb-review.md#从原理图转-pcb-并核对)。
