# 3.7 预走线优化

根据当前布局和真实连接，选择引脚交换、器件旋转或出线空间调整，减少明显交叉、绕行和局部拥挤，为后续走线准备条件。

每轮按实际需要选择算法，不必全部运行。

## 一、拿到什么

复用当前 PCB、电路设计稿和已有规则，明确：

- 器件位置、朝向、真实焊盘及网络连接。
- 允许交换的引脚集合及其功能、电气和固件条件。
- 允许旋转、移动的器件，以及固定件和外部障碍。
- 关键电气关系、线宽间距、允许布线层及必要预留。
- 本轮优化目标、调整范围和计算预算。

已有资料直接复用。引脚是否可交换以器件资料和实际用途为依据，不凭网名或位置推断。

## 二、选择优化方法

### 引脚交换

在已确认的可交换集合内，比较不同的引脚分配，减少连接交叉和明显折返。比较时保留功能复用、电气能力、上电状态、固定用途及固件要求。

### 器件旋转

保持器件中心位置，在允许的朝向中比较连接安排。先尝试单个器件，必要时再比较少量组合；核对全部受影响连接及旋转后的占位，不只消除某两条线的交叉。

### 出线空间优化

针对主控等连接密集的器件，结合各侧实际引出的连接、线宽间距、允许层和周围障碍，判断哪些位置需要为出线、转弯或换层腾出空间。

在本轮允许范围内调整附近器件，优先处理拥挤的一侧或局部通道，同时保留关键电气关系和必要的近距离配套。不把四周统一扩大间距作为默认做法。

具体移动和几何验收复用块内布局已有能力。本项以改善出线条件为目标；块内布局用于扩大重排范围的“借一层邻居”另按对应规则处理。

## 三、比较与采用

按所选方法比较全部受影响关系：引脚交换和旋转主要看连接交叉及折返，出线空间调整主要看局部出口和通道是否改善，同时检查连接长度、关键电气要求、装配及外部干涉。

不同网络的交叉与同网连接分别处理。飞线和空间指标用于比较方案，实际布通情况由后续走线验证。

采用引脚交换方案时，同步电路设计稿、原理图、PCB 网络和受影响的固件映射。采用旋转或移动方案时，核对器件、相关位号及范围外保持情况。写回、保存和回读沿用现有公共入口与 [0.3](0.3-easyeda-pro.md)。

## 四、交出什么

交出选定方案，说明：

- 本轮问题、所用方法、调整对象和范围。
- 器件旋转、位置调整或引脚交换清单及依据。
- 受影响网络、前后改善和代价、检查结论及未决项。
- 对应工程版本，以及实际写入和保存状态。

算法步骤、参数、支持范围和可复现案例放在技术参考中。后续新增方法按同样方式说明适用问题、允许变化、比较依据和输出。

## 五、什么时候结束

获得满足本轮要求的改善方案后停止；没有找到改善或达到预算时，保留当前方案并报告剩余问题，交给后续走线处理。

本阶段不要求把所有交叉消除。确实妨碍后续工作的条件缺口按影响处理，不把“没有找到更优方案”当成流程失败。
