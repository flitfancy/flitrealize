# 3.8 走线、铜路径与局部重布

拿到同一版本的布局、实际网络、层与规则，连接网络、检查铜路径，并把失败反馈给需要调整的范围。只做布局比较时，预走线用途按[功能块布局](3.5.1-block-layout.md#二做什么)和[块内布局](3.5.2-fine-layout.md#局部重排与反馈)组织。

## 选择本次范围

先明确网络、关键端点、角色、允许层、线宽和孔条件，区分需要求解、保护和明确允许重布的已有铜。使用实际焊盘归属、板边和障碍，不从其他软件层号或网络名称猜规则。

离线出口、路径、孔位、铜路径、有限回退、清理与组合使用同一[工具技术参考](technical/pcb-prerouting.md)。原生 FR 写入与保存走[现有执行链](providers/easyeda-pro/pcb-autorouting.md)，不把离线候选当成已经写板。

## 检查路径、重布与清理

关键端点的直线距离、铜路径投影和实际回流分别检查。路径图帮助定位绕行、换层和瓶颈，不独立证明电磁、温升或载流通过。

局部撤线重布只处理明确允许的网络或角色，保留共享铜、原连接与范围外内容；撤回后重新核对完整受影响端点。清理保护关键电源、独立采样及配对网络，组合只比较已有路径集合中的相容方案。具体条件和独立铜验收沿工具参考，不复制算法或默认清空整板。

## 反馈与交接

失败时记录网络、端点、出口／通道、阻挡器件或铜对象及证据，未知位置明确保留。AI 据此提出最小调整范围，再用已有布局入口生成和核验候选；当前没有通用的自动选器件移动闭环。

候选变化后重新绑定几何与规则。有限搜索无路、预算耗尽、规则拒绝和能力不支持分别报告；达到本轮目标或预算后停止，交出已验路径、实际写入／保存状态及具体阻塞项。

整板完成条件见[PCB 总览](3.1-pcb-review.md#完成本阶段)。正式候选仍需实际铜、原生检查、铺铜、回流及保存证据，离线通过不能替代这些结果。
