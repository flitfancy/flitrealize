# 1.2 器件选择与资料

需要确定器件、匹配库存或核对资料时读本页。器件选择服务于当前电路，不依赖 EDA 元件库；已确认的部分可以复用，从本次缺口开始。

## 拿到什么、交出什么

拿到器件在电路中的作用、工作条件，以及相关机械、供应和成本限制。交出当前采用的器件或少量候选、资料依据、封装要求及未决项，交给原理图设计。

本次可以只核对一个参数、一个器件或一组候选，不要求每次从库存查询到 EDA 绑定走完整流程。

## 明确作用与要求

先说明器件做什么，再找真正影响选择的条件：电压、电流、功率和频率范围，精度、噪声、温升或时序，封装与散热，以及必须具备的保护或控制行为。只展开本次选择需要的参数，保留限制的来源和允许替代范围。

涉及具体型号特性的判断，要确认准确型号及必要后缀。身份已确定不代表电气适用性与封装也已核验；进入具体连接或 PCB 实现前，确认本次所需的引脚、封装和尺寸。

## 库存与候选

优先复用已有库存信息。器件身份可靠、参数满足要求且封装可用时才采用；没有合适库存时，比较少量候选，记录采购缺口。

库存数量和可用状态来自用户库存记录，由已有库存工具读取。资料缓存只说明资料可取得；当前产品页的供应信息也不等于用户已有库存。没有适用库存工具时说明缺口，继续处理不依赖该查询的设计部分。

## 核对资料与当前判断

制造商、官方商城和授权分销商资料可核对型号、制造商、采购编号、封装及供应情况。已确认且无冲突的基础信息可以复用。电气设计优先读准确器件的制造商数据手册，重点核对当前电路需要的工作范围、引脚、关键参数、外围连接和保护／启动／故障行为。

身份、后缀或封装有冲突，设计依赖曲线、温升、瞬态、降额或机械时序，资料没有回答核心功能，或器件承担保护、隔离和故障关断时，深入相关章节。取得资料、缓存命中和下载成功都不是选型通过。

### 使用资料解析器

需要复用或取得数据手册时，可用已有解析器。它先查本地资料，再按已提供的资料 URL 或 LCSC 产品来源取得缺失资料；只有型号而无缓存或 URL 时，返回补查线索。它不查询实际库存，也不替代选型判断。

只有调用工具时才读[器件资料工具参考](technical/parts-data-tools.md)。该页维护命令、缓存检查及可选库存汇总；输入与结果字段统一见[器件资料数据约定](../schemas/parts.md)。

## 接受、保留候选或说明未决

当前要求已有依据，身份、关键参数和本次所需封装可用时，接受器件；需要继续比较时保留候选及取舍。按规格允许替代的通用器件，不必提前锁定唯一型号。身份与封装分别记录，字段定义以 [电路设计稿器件说明](../schemas/schematic.md#器件)和对应结构定义为准。

未决问题说明影响、继续条件和所需证据。问题若可能改变当前电路能否成立、保护行为、额定条件、引脚或封装，先解决，或明确替代方案与受限范围；不能只写“样机再测”就视为已经通过。其他问题可作为带条件的样机确认项，写明测试条件、预期及失败后的调整范围。未受影响的设计可以继续。

## 写回主文稿与电路设计稿

器件章节保留用途、采用的型号或完整规格、封装、采购身份、关键参数与选择理由、资料入口、替代条件，以及仍需确认的问题。候选比较留在正文，当前设计选择进入 [电路设计稿](../schemas/schematic.md#器件)；未确定的器件保留未决状态。

按 [0.1 更新约定](0.1-continuation.md#信息归属与更新)同步本次受影响内容。进入 EDA 时再按[器件绑定与放置](providers/easyeda-pro/2.1-r-component-batch.md)绑定已接受选择的库器件、符号、封装和引脚映射。制造准备从已接受器件或允许替代范围中确定本次实际料号。
