# 3.3 布局输入与规则转置

需要生成或刷新布局求解输入时读取。复用上游设计和当前 PCB，核对共同事实，再按本次任务进入对应转置：

- [3.3.1 功能块布局输入与转置](3.3.1-block-layout-inputs.md)：准备功能分组、中心连接关系、大致占位和整体限制。
- [3.3.2 块内布局输入与转置](3.3.2-fine-layout-inputs.md)：准备局部成员、真实焊盘关系、调整范围及验收条件。

只读检查、明确移动和应用已有候选，按 [3.1 任务分流](3.1-pcb-review.md#本次布局任务)使用对应入口，不重复执行整套求解准备。

## 共同输入

复用当前电路设计稿、原理图连接核对结果、封装映射和当前 PCB，取得：

- 功能块用途、完整器件成员、引脚与网络关系。
- 实际器件、焊盘、位号、位置、方向、锁定和已有铜。
- 板框、机械锚点、固定接口、禁区及预留用途。
- 已确认的项目规则、本轮任务范围和例外。

设计意图由电路设计稿提供，实际几何由 PCB 回读取得。来源版本与对象映射应能对应；冻结快照注明来源，已有结果按变化范围核对后复用，不手填第二套坐标或网表。

## 共同准备

板框、层叠与禁区的实际落实见 [3.2](3.2-pcb-foundation.md)。本轮不可改变的孔、接口、外壳开口和机械方向先明确，预留空间说明用途。暂定条件保留依据和允许变化范围，不把未知当作无约束。

层数、层用途、重要网络参考层及制造条件沿用项目选择。会影响本轮几何或路径的条件先确定；可后续细化的内容保留影响说明。介质、铜厚和阻抗依据来自板厂能力或明确假设。

首次整体 PCB 准备安排网络配色检查及必要设置，已有有效配色复用。后续局部工作和独立离线求解不重复要求整板配色。执行与状态记录见[配色顺序](providers/easyeda-pro/3.4-r-pcb-net-color.md#布局前的配色顺序)。

已有铜如实记录，并按所选入口核对支持范围，不要求布局前先创建实际铜。

## 核对与复用

复用现有准备入口，核对来源、身份、引脚映射、网络、单位、几何及规则一致性。影响本轮输入成立的缺项先处理；范围外已有问题按 [0.3](0.3-easyeda-pro.md)处理，当前可修复的问题可以作为起点。

AI 补充本轮工程判断，脚本关联已确认事实和结构化规则。文字要求尚不能转置时保留为未覆盖项，不因准备无报错就认定全部要求已参与计算。

输入或现场变化后，只刷新受影响的数据及依赖。继续使用旧结果前核对其适用性，不覆盖期间的人工修改。

## 交出什么

交出来源一致的基础输入、准备回执和诊断，说明本轮范围、已知限制、暂定条件、未覆盖项及适用的配色状态，再进入对应转置。

共用字段见[布局数据约定](../schemas/pcb-layout.md)，准备覆盖范围见[布局输入技术参考](technical/pcb-layout-inputs.md)，现场读取与执行命令见[布局与空间](providers/easyeda-pro/3.5-r-pcb-placement.md#输入准备与候选求解)。
