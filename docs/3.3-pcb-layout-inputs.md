# 3.3 布局输入与规则转置

复用上游结构化设计和当前 PCB，合并本轮范围与例外，转成求解约束、目标和有效输入。AI 只补本轮工程判断，不在每轮重新总结散文或重造规则。板框、层叠与禁区的现场落实见 [3.2](providers/easyeda-pro/3.2-pcb-foundation.md)；本页负责输入归属、准备顺序和继续条件。

## 拿到什么

读取当前原理图／电路设计稿、封装映射与连接核对结果，使用同一版本的 PCB 基线或注明来源的冻结快照，并明确本轮调整范围和例外。已有铜如实记录并按所选入口核对支持范围；不要求布局前先创建实际铜。

## 复用已确认设计与本轮边界

复用已确认的块名、用途、成员、块间连接和电源树，以及板框、固定接口、机械锚点、安装孔、禁区与预留用途。结合封装、重要网络、外壳／高度条件、测试和调试访问，形成功能块布局可用输入。

必须检查并按既定规则设置网络配色，已有正确配色保留；用途、分类、保存回读、显示确认及无法执行时的处理只在[配色顺序](providers/easyeda-pro/3.4-pcb-net-color.md#布局前的配色顺序)维护。只读或离线任务记录未完成部分，不因流程顺序附带 EDA 写入。

### 机械与层叠的前置条件

本轮不能改变的孔、接口、外壳开口和机械方向先明确，预留空间注明用途。板框或机械条件仍可在允许范围内收敛，但暂定值须有依据和变化范围；不能把未知当作无约束，也不为求解暗改固定件。

层数、层用途和重要网络参考层结合布线密度、电流、散热、高速／敏感信号、板厚、制造能力与成本选择。物理介质、铜厚及阻抗依据来自板厂能力或明确假设。会影响本轮几何或路径的条件在求解前确定，变化后刷新相关输入；后续可收敛项保留影响说明。

前期板框、层叠与禁区的实际落实见[3.2](providers/easyeda-pro/3.2-pcb-foundation.md)。脚本求解前复用输入准备完成身份关联和规则检查，字段与覆盖范围见[布局输入参考](technical/pcb-layout-inputs.md)。身份、映射和规则冲突先解决；当前可修复间距问题可作为起点。只有缺口阻止当前工作或可能推翻关键器件、封装、接口和板框时才回上游。

## 转置并核对有效输入

复用现有 prepare 和规则合成，把上游块与连接、电气关系、当前器件／焊盘／位号及项目配置关联起来；本轮固定范围、调整范围、可借空间和例外使用已有请求与配置声明。身份、网络和几何由脚本关联，不再手填第二套坐标或网表。

检查来源版本、对象映射、单位、规则矛盾、已编译关系和未覆盖项。只有当前支持的结构化关系进入对应编译；文字要求和暂未覆盖的条件仍保留为工程核对项，不能因准备无报错而宣称全部已编译或验收。

字段与规则合成语义统一在[布局数据约定](../schemas/pcb-layout.md)维护，准备覆盖范围仍见[布局输入技术参考](technical/pcb-layout-inputs.md)。输入准备、冻结输入复用和软件适配层命令见[3.5 布局与空间](providers/easyeda-pro/3.5-pcb-placement.md#输入准备与候选求解)，不在本页复制命令和字段定义。

## 交出什么、何时继续

交出绑定同一来源的有效布局输入、准备回执与诊断，说明已知规则、本轮例外、暂定项、未覆盖条件及配色检查状态。完整数据和几何保留在原制品与派生产物中。

本轮所需块归属、板框依据、固定与调整范围、主要连接已明确，输入矛盾已处理，配色按 [3.4](providers/easyeda-pro/3.4-pcb-net-color.md#布局前的配色顺序) 检查并记录后，进入 [3.5.1 功能块布局](3.5.1-block-layout.md)；已有功能块布局结果的局部任务按 [3.5.2 块内布局](3.5.2-fine-layout.md) 复用相关准备结果。输入或现场变更后刷新受影响的数据，不用旧候选覆盖期间修改。
