# 3.5.1 功能块布局

功能块布局根据功能分组、器件尺寸、板框与机械限制，以及各功能块之间的电气关系，安排它们的大致位置、朝向和占用空间，形成候选供[块内布局](3.5.2-fine-layout.md)继续。

## 一、拿到什么

复用 [3.3 布局输入与规则转置](3.3-pcb-layout-inputs.md)整理的资料：

- 功能块的用途、器件成员和真实封装尺寸。
- 板框、机械位置、固定件、接口方向、禁布区和装配间距。
- 功能块之间的连接、供电关系，以及明确的靠近、隔离和关键路径要求。
- 影响空间分配的连接数量、线宽需求和通道预留。
- 本轮调整范围和计算预算。

已有资料直接复用，缺项和冲突回到对应来源处理。

## 二、做什么

核对各功能块的成员，根据器件尺寸和必要间距估计所需空间，再结合机械限制和块间电气关系，生成不同的位置、朝向和占位方案。

比较候选时，先检查明确的限制是否满足，再看：

- 各块是否放得下，空间分配是否合理。
- 相关功能块的相对位置、接口朝向和主要连接方向是否合适。
- 连接集中或需要粗线的地方是否留有空间。
- 是否存在明显挤占、绕行或空间浪费。

连接距离、占位和留白可以辅助量化，但不能只凭总分判断候选。功能块布局不要求完成实际走线，也不需要划分簇或精排块内器件。

## 三、交出什么

交出选定候选和摆放图，说明：

- 各功能块的成员、大致位置、朝向和占用空间。
- 固定要求、主要块间关系和通道预留。
- 分配依据、检查结果及未决问题。
- 对应工程版本，以及是否已写入和保存。

块的占位用于指导块内布局，不固定其全部内部器件。块内布局继续处理块内的簇和器件；发现空间不足或条件冲突时，反馈具体原因，再调整相关块的安排。

## 四、什么时候结束

各功能块的安排明确，满足本轮限制，主要电气关系已有安排依据后，可以进入块内布局。

获得满足要求的候选后停止。预算耗尽、空间不足或规则冲突时，交出最佳已验候选或具体阻塞原因。稳定结果同步到[项目主文稿](0.1-continuation.md)。

## 执行说明

输入字段、求解命令和支持范围见[布局输入与求解参考](technical/pcb-layout-inputs.md)；连接 EDA、写回、保存和回读见[布局与空间](providers/easyeda-pro/3.5-pcb-placement.md)。

当前公共求解仍以器件为变量，功能组主要提供聚拢偏好，尚未完整实现上述功能块空间分配。该实现缺口单独处理。
