# 3.5.1 功能块布局

以已确认的功能块为单位，依据块间连接和功能关系，结合板框、机械接口与空间需求，安排各块的大致位置、朝向和占用区域，形成整体分布方案，供[块内布局](3.5.2-fine-layout.md)继续。

## 一、拿到什么

复用 [3.3.1 功能块布局输入与转置](3.3.1-block-layout-inputs.md)整理的资料：

- 功能分组：来自电路设计稿，明确每个功能块的用途和完整器件成员。
- 块间关系：来自跨块网络及其用途，明确哪些块相互连接、如何协作，以及已有的靠近、隔离和关键路径要求。
- 机械条件：板框、安装位置、固定件、外部接口、方向要求和禁布区。
- 空间需求：根据各块成员的真实封装尺寸、装配要求，以及连接数量、线宽需求和必要留白估计。
- 本轮范围：允许调整的功能块、固定要求、允许姿态和计算预算。

已有资料直接复用。成员归属或跨块关系不明确时，回到设计来源核对，不凭块名或当前器件位置猜测。

## 二、做什么

### 安排整体分布

先根据块间关系确定相对安排：联系紧密的块优先相邻，主要连接方向尽量顺畅，需要隔离的块保持分离。共享电源或地本身不作为所有功能块相互靠拢的依据。

再结合接口位置、固定件和板框，确定各块的大致区域、朝向与空间分配。连接集中或需要较宽通道的块间位置保留适当空间，避免明显挤占和绕行。

功能块作为整体安排，但不要求内部器件形成固定形状。成员与封装尺寸用于估计占位，必要时可作大致展开以检查是否放得下；不要求划分簇，块内器件和引脚的具体排列留给块内布局。

本阶段的间距设置独立配置，已有装配要求继续满足，不把阶段默认值自动带入块内布局。具体字段与计算方法见[技术参考](technical/pcb-layout-inputs.md#功能块阶段的求解评分与验收)。

### 比较候选

先检查板框、固定位置、禁区、装配及已确认电气要求，再比较：

- 块的相对位置是否体现已有连接和功能关系。
- 接口朝向与主要块间连接方向是否合理。
- 各块空间是否足够，必要通道是否留出。
- 是否存在明显拥挤、分散或空间浪费。

距离、占位和留白可以辅助量化，分别说明结果，不能只凭总分选择候选。功能块布局不以块内精排、实际走线完成、逐脚出口或具体孔位规划作为完成条件。

## 三、交出什么

交出选定候选和整体分布图，说明：

- 完整功能块清单、本轮参与调整的功能块，以及未参与的功能块和原因；各块成员沿用已确认的分组。
- 各功能块的大致区域、朝向和占用空间。
- 主要块间关系及位置安排依据。
- 固定要求、通道预留、检查结论及未决问题。
- 对应工程版本，以及是否已写入和保存。

区域分配用于指导块内布局，不固定全部内部器件，也不自动成为长期禁区或不可调整的边界。必须长期遵守的机械、电气要求继续按原来源维护。

块内布局发现空间不足或关系冲突时，反馈具体对象和原因，再调整受影响功能块的安排。

## 四、什么时候结束

各块的大致分布明确，块间关系得到合理体现，并满足本轮限制后，可以进入块内布局。

获得满足要求的候选后停止。预算耗尽、空间不足或规则冲突时，交出最佳已验候选或具体阻塞原因。已有问题与本轮变化按 [0.3](0.3-easyeda-pro.md)处理，稳定结论同步到[项目主文稿](0.1-continuation.md)。
