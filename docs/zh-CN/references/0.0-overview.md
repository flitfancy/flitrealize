## 主流程

```text
CURRENT_HANDOFF.md
  ↓
1.1 需求与架构
  → 1.2 器件选择与资料
  → 2.1 原理图设计与 Contract
  → 2.2 EDA 原理图
  → 3.2 层、板框和功能性 keepout
  → 3.1 布局与关键布线
  → 3.2 重铺并确认参考铜
  → 3.3 回流与接地
  → 3.1 整板检查
  → 4.1 制造准备
  → 5.1 样机验证与改版
  → 6.1 产品化，仅在用户要求时
```

`CURRENT_HANDOFF.md` 是贯穿整个项目的人类主文稿。每个阶段把稳定结论更新到对应章节，机器事实仍由 Contract、EDA 源文件、制造输出和原始测试记录保存。

项目续接使用 [0.1](0.1-continuation.md)；一个问题需要多轮实验时使用 [0.2](0.2-debug-loop.md)；进入 EasyEDA Pro 时使用 [0.3](0.3-easyeda-pro.md)；只有音频硬件读取 [1.3](1.3-audio-systems.md)。

主 Skill 负责全流程和共同规则，每份参考只负责一个阶段或一个有边界的问题。当前任务已经能够继续或完成时，停止加载更多参考。
