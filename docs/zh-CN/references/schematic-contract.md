# 从概念到原理图契约

处理需求、架构、器件选择、引脚映射或原理图评审时读取本参考。

## 把意图转成有边界的设计

只询问会改变架构或验收的问题：

- 电源范围、极性、瞬态、可用及峰值电流；
- 主机/协议、电压域、线缆和热插拔条件；
- 传感器/负载、精度/速率/启动和故障行为；
- 外壳、环境、热/声学/光学约束；
- 装配、维修、数量、成本和可信扩展；
- 可观察性、安全默认状态、恢复和测试方法。

记录明确非目标。在优化所有器件前先建立框图和电源树。每个功能块记录目的、接口、电流、启动/复位、故障传播、测量方法和供应风险。优化内部实现前冻结稳定外部接口。

## 约束跨领域假设

识别依赖固件、时序、声学、机械、散热、外壳几何或陌生组合路径的功能。按后果选择证据：聚焦计算、仿真、模块、面包板或明确到货/上电测试。缺失证明及其后果清楚时，个人原型可以条件推进。

各自正确的应用电路不能证明组合系统能工作。

## 保持机器可检查意图

对生成或评审需要比较的事实使用项目契约/配置：

- 元件角色与精确采购/封装身份；
- 预期引脚/焊盘及关键或完整 pin-to-net 映射；
- 数值、额定值、公差、替代和特殊封装政策；
- 接口方向、总线地址、上拉域和电源消费者；
- 测试点、板卡版本和源制品位置。

原理图实现设计；契约独立记录意图。把导出网表或结构化 capture 与契约比较。引脚映射变化需要作为一个受控增量，同时更新拥有该事实的契约、原理图源/生成器、固件接口、capture 预期和针对性测试。

## 使用正确事实源

1. 制造商数据手册：电气事实和推荐电路。
2. 实时库 capture：符号/封装几何和平台身份。
3. 当前受控 BOM：选定数值、额定值、公差和器件。
4. 会话回忆只能提供线索，不能作为证据。

平台 API 使用当前官方文档，并用只读探针确认陌生行为。不能只靠训练记忆放置新器件或回答关键参数。

精确数据手册版本只有在支持必须保持可复现的实质决策时才归档；不要把普通无源件变成文档工作。

## 按功能顺序评审

1. **电源入口：**范围、反接/浪涌/ESD、保险行为、回流和连接器额定值。
2. **稳压器与负载：**压差、损耗/温度、使能默认状态、电容值/降额/稳定性、启动、放电和峰值电流。
3. **电压域：**转换方向、阈值、上拉、复位和保护器件电源兼容性。
4. **接口：**配对引脚/方向、断开/线缆故障行为和 ESD 路径。
5. **数字总线：**地址、等效上拉、电容、拓扑和恢复。
6. **传感器/执行器：**主电路、开口、EP/NC、校准/处理和安全驱动状态。
7. **BOM/封装：**MPN/封装、降额、生命周期、替代、库存证据及采购身份与几何 donor 的分离。

ERC 是已配置连通性证据，不证明拓扑、额定值或系统行为。对有意例外设定边界。

## 仅在有用时增加人类总览

复杂项目或手工 EDA 协作可从契约和 BOM 派生 `ALL_VIEW.md`（或等效总览），内容可包括元件作用、功能块、可互换引脚以及后续布线计划。同步其版本指针，但对于契约已经易读的小项目，不把该派生文件作为前置条件。

## 常见陷阱

- 负载开关不自动等于限流器。
- 同名或同电压网络不能证明电压域等价且安全。
- 平均电流不能替代峰值/瞬态分析。
- 未连接焊盘必须分类为 DNC、NC、地/散热或错误。
- 图纸整洁不能替代功能契约。
