# 3.1 PCB 设计与检查

原理图和主要器件已经确定，需要完成板框、层叠、布局、布线、铺铜或 DRC 时读取本参考。

本阶段把原理图中的电气意图落实为实际 PCB。制造文件导出和板厂预览留给制造准备阶段。

## 确认输入

开始 PCB 时，读取当前已有输入。适用项可以是已确认、暂定或明确不适用。只有缺口会导致当前 PCB 无法继续，或很可能推翻主要器件、封装、接口及板框时，才返回上一阶段；其余缺口记录为假设，在 PCB 阶段继续收敛。

确认当前使用的：

- 原理图和机器 Contract；
- 器件与准确封装；
- 板框、安装孔和接口位置；
- 外壳、高度和机械限制；
- 功能块和电源树；
- 重要网络的电流、电压、敏感性和拓扑要求；
- 天线、声学、光学、散热和装配 keepout；
- 需要保留的测试点和调试访问。

这些输入可以分别标记为已确认、暂定或不适用。暂定项应说明它限制哪部分 PCB 工作以及何时复查。

如果仍有问题会改变主要器件、封装、引脚、电源结构或接口，应先返回原理图阶段解决。

## 建立 PCB 基础

先确定：

- 板框；
- 安装孔；
- 边缘连接器；
- 机械固定点；
- 禁布和限高区域；
- 铜层数量；
- 每层的主要作用；
- 主要参考平面；
- 板厂能够提供的基础制造能力。

板框、接口和安装孔优先满足产品与外壳，不为了布线方便随意移动。

## 选择层叠

根据实际设计选择铜层数量，不预设所有项目都使用两层或四层。

考虑：

- 布线密度；
- 关键网络是否具有连续参考；
- 电源和地平面需求；
- 电流和散热；
- 高速、RF、模拟或低噪声要求；
- 板厚、阻抗和制造能力；
- 成本和原型数量。

选择能够满足当前设计的合理层叠。层数更多不自动代表设计更好，层数更少也不能以破坏回流、布线和热设计为代价。

记录每层的主要作用，以及重要信号使用的参考层。物理介质厚度、铜厚和阻抗值应来自当前板厂能力或明确设计假设。

## 按功能关系布局

先放置具有机械位置要求的对象：

- 连接器；
- 开关和按钮；
- 传感器开口；
- 天线；
- 麦克风和扬声器接口；
- 安装孔；
- 调试接口；
- 指示灯和用户可见器件。

然后按功能关系放置电路：

```text
连接器
    → 输入保护
    → 电源或接口电路
    → 负载或处理器
```

重点关系包括：

- 保护器件靠近能量或干扰入口；
- 去耦靠近对应电源引脚；
- 开关电源功率环路紧凑；
- 反馈和采样路径远离开关节点；
- 晶振、参考和敏感模拟路径靠近对应器件；
- 大电流、发热和噪声电路远离敏感模块；
- 测试、插拔、返修和装配能够实际访问；
- 器件方向符合 pin 1、接口方向、散热和走线需求。

布局目标是形成清楚的电流与信号路径，不是让器件在视觉上整齐排列。

完成一个关键功能块和整体分区后先检查，再扩大到完整布局。

## 必要时局部调整引脚

粗布局完成后，如果 MCU、FPGA 或其他可配置器件的当前引脚造成明显交叉、绕行、拥挤或过孔，可以考虑局部调整。

使用 [2.1 原理图设计与契约](2.1-schematic-contract.md) 中的 `unused_configurable_only` 策略。不搜索全部排列，也不为理论最优打乱已经稳定的接口。

实际修改后先同步 Contract、原理图和受影响的固件接口，再继续正式布线。

## 建立网络规则

根据 `2.1` 提供的初步电气意图，结合实际层叠和铜厚确定网络规则。

对重要网络考虑：

- 连续和峰值电流；
- 允许压降；
- 工作电压；
- 允许温升；
- 走线长度；
- 外层或内层；
- 过孔数量和尺寸；
- 回流路径；
- 差分、阻抗或长度关系；
- 与噪声源和敏感网络的间距。

制造商给出的最小线宽和间距只是制造下限，不是所有网络的设计值。

焊盘逃逸可以比主干更窄，但应限制缩颈长度，并尽快过渡到正常线宽。高电流网络需要同时检查走线、铺铜、过孔和连接器中的最窄位置。

普通项目不需要为每个信号建立复杂网络类，只为实际存在不同要求的网络分类。

## 按风险顺序布线

优先完成会决定其他走线路径的网络，例如：

1. 主要电源和返回路径；
2. 开关电源功率环路；
3. 高速、时钟和差分接口；
4. 反馈、采样和敏感模拟信号；
5. 保护和故障关断路径；
6. 普通控制和低速数字信号。

每条关键路径检查：

- 实际拓扑；
- 支路和 stub；
- 换层位置；
- 参考平面；
- 回流是否连续；
- 与相邻噪声源的耦合；
- 过孔和缩颈；
- 测试点是否形成不必要支路。

自动或批量布线可以用于有清楚边界的普通剩余网络，但完成后仍应按网络用途检查实际路径。

## 处理地、平面和铺铜

接地方式由实际电流和信号回流决定。

通常优先保持连续参考，不为了区分“模拟地”和“数字地”机械切割平面。需要分区时，应先说明电流如何流动以及跨区信号怎样返回。

检查：

- 去耦电流回路；
- 功率器件和热焊盘接地；
- ESD 泄放路径；
- 信号换层后的参考回流；
- 地铜孤岛；
- 狭窄通道；
- 被 keepout 或开槽切断的返回路径；
- 铺铜后实际剩余的铜形状。

地过孔用于完成实际回流、散热或屏蔽，不把数量和规则网格本身当成目标。

使用 EasyEDA Pro 时：

- 层叠、板框、keepout 和实际铺铜见
  [3.2-pcb-foundation.md](providers/easyeda-pro/3.2-pcb-foundation.md)；
- 换层回流和接地过孔见
  [3.3-pcb-grounding.md](providers/easyeda-pro/3.3-pcb-grounding.md)。

实际顺序为：先用 `3.2` 建立层、板框和功能性 keepout；回到本文件完成布局和关键布线；再回到 `3.2` 重铺并确认参考铜；随后使用 `3.3` 处理回流和接地，最后回到本文件完成整板检查。

## 处理热和机械条件

检查：

- 功率器件的铜面积和散热路径；
- 热过孔和散热焊盘；
- 发热器件对传感器、电池和外壳的影响；
- 空气流动和密闭外壳；
- 元件高度和装配方向；
- 连接器插拔空间；
- 螺丝、支柱和外壳受力；
- 返修工具和探针能否接近；
- 声孔、光路、气流和天线区域是否保持有效。

空白区域可能服务于天线、声学、散热、装配或布线，不需要为了视觉紧凑填满器件。

## 检查 PCB

完成布局和布线后检查：

- 是否仍有未布网络；
- 网络类是否实际分配到正确网络；
- 关键线宽、间距、过孔和拓扑；
- 电源路径是否存在缩颈；
- 差分和阻抗要求；
- 参考平面和换层回流；
- 铺铜、孤岛和意外断开；
- 板边、孔和槽的间距；
- 焊盘、阻焊桥和钢网需求；
- pin 1、极性和器件方向；
- 丝印是否压住焊盘或被器件遮挡；
- 顶底层器件方向；
- 机械碰撞、限高和插拔空间；
- 测试点是否可访问。

运行当前项目已经配置的 DRC，并查看具体规则和剩余问题。

DRC 只能说明当前规则能够识别的几何问题，不代替对电源、回流、热、机械和功能路径的检查。

## 完成本阶段

进入制造准备前，确认：

- PCB 源文件已经保存；
- 主要器件、板框、孔和接口位置正确；
- 所有需要连接的网络已经布通；
- 关键电源、信号和返回路径符合当前设计；
- 实际铺铜已经更新；
- 引脚调整已经同步回原理图和 Contract；
- DRC 没有未解释的当前问题；
- 机械、装配、测试和散热条件已经检查。

Gerber、钻孔、BOM、CPL 和板厂预览在 [4.1-production-handoff.md](4.1-production-handoff.md) 中处理。
