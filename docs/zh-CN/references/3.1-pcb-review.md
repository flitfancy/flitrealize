# 3.1 PCB 设计与检查

原理图和主要器件已经确定，需要完成板框、层叠、布局、布线、铺铜或 DRC 时读取本参考。

本阶段把原理图电气意图落实成实际 PCB。稳定设计进入 `CURRENT_HANDOFF.md` 的 3.x 章节，完整几何保存在 PCB 源文件中。

## 确认输入

开始 PCB 时读取：

- 当前原理图和 Contract；
- 器件与准确封装；
- 板框、安装孔和接口位置；
- 外壳、高度和机械条件；
- 功能架构和电源树；
- 重要网络的电流、电压、敏感性和拓扑；
- 天线、声学、光学、散热和装配 keepout；
- 测试点和调试访问。

输入可以是已确认、暂定或不适用。

只有缺口会阻止当前 PCB 继续，或者很可能推翻主要器件、封装、接口和板框时，才返回上一阶段。其余条件在 PCB 阶段继续收敛。

## 建立物理基础

先确定：

- 板框；
- 安装孔；
- 边缘接口；
- 机械固定点；
- 禁布和限高区域；
- 铜层数量；
- 每层作用；
- 主要参考平面；
- 当前制造能力。

板框、接口和安装孔优先满足产品和外壳。

## 选择层叠

根据实际设计选择铜层数量，考虑：

- 布线密度；
- 关键网络参考；
- 电源和地平面；
- 电流和散热；
- 高速、RF、模拟或低噪声；
- 板厚、阻抗和制造能力；
- 成本和原型数量。

记录每层作用和重要信号的参考层。物理介质、铜厚和阻抗值来自当前板厂能力或明确设计假设。

## 按功能布局

先放置具有机械位置要求的对象：

- 连接器；
- 开关和按钮；
- 传感器开口；
- 天线；
- 麦克风和扬声器接口；
- 安装孔；
- 调试接口；
- 用户可见器件。

然后按功能关系放置：

```text
连接器
    → 输入保护
    → 电源或接口电路
    → 负载或处理器
```

重点检查：

- 保护器件靠近入口；
- 去耦靠近电源引脚；
- 开关电源功率环路紧凑；
- 反馈和采样远离开关节点；
- 晶振、参考和敏感模拟路径靠近对应器件；
- 大电流、发热和噪声电路远离敏感模块；
- 测试、插拔、返修和装配能够访问；
- 器件方向符合 pin 1、接口、散热和走线关系。

布局用于建立清楚的电流和信号路径，不追求装饰性对齐。

完成一个关键功能块和整体分区后先检查，再继续完整布局。

## 局部调整引脚

粗布局后，可配置器件的当前引脚如果造成明显交叉、绕行、拥挤或过孔，可以使用 2.1 中的 `unused_configurable_only` 策略。

实际修改后先同步 Contract、原理图、主文稿和受影响的固件接口，再继续正式布线。

## 建立网络规则

根据原理图提供的电气条件，结合实际层叠和铜厚确定：

- 连续和峰值电流；
- 允许压降；
- 工作电压；
- 允许温升；
- 走线长度；
- 外层或内层；
- 过孔数量和尺寸；
- 回流路径；
- 差分、阻抗或长度关系；
- 与噪声源和敏感网络的间距。

制造最小线宽和间距只是制造下限，不是所有网络的设计值。

焊盘逃逸可以比主干更窄，但应限制缩颈长度。高电流网络同时检查走线、铺铜、过孔和连接器中的最窄位置。

只为实际存在不同要求的网络分类。

## 按风险布线

优先完成：

1. 主要电源和返回路径；
2. 开关电源功率环路；
3. 高速、时钟和差分接口；
4. 反馈、采样和敏感模拟；
5. 保护和故障关断；
6. 普通控制和低速数字信号。

每条关键路径检查：

- 实际拓扑；
- 支路和 stub；
- 换层；
- 参考平面；
- 回流连续性；
- 与噪声源的耦合；
- 过孔和缩颈；
- 测试点形成的支路。

自动或批量布线可以用于边界清楚的普通网络，完成后仍按网络用途检查。

## 地、平面和铺铜

接地方式由实际电流和信号回流决定。

通常优先保持连续参考。需要分区时，先说明电流怎样流动以及跨区信号怎样返回。

检查：

- 去耦回路；
- 功率器件和热焊盘；
- ESD 泄放；
- 信号换层后的参考回流；
- 地铜孤岛和狭窄通道；
- keepout 或开槽造成的断开；
- 铺铜后的实际铜形状。

地过孔用于完成回流、散热或屏蔽，不把数量本身当成目标。

使用 EasyEDA Pro 时：

- 层叠、板框、keepout 和参考铜见
  [3.2-pcb-foundation.md](providers/easyeda-pro/3.2-pcb-foundation.md)；
- 换层回流和接地过孔见
  [3.3-pcb-grounding.md](providers/easyeda-pro/3.3-pcb-grounding.md)。

顺序为：

```text
3.2 建立层、板框和功能性 keepout
    → 3.1 完成布局和关键布线
    → 3.2 重铺并确认参考铜
    → 3.3 处理回流和接地
    → 3.1 完成整板检查
```

## 热和机械

检查：

- 功率器件铜面积和散热；
- 热过孔和散热焊盘；
- 发热器件对传感器、电池和外壳的影响；
- 气流和密闭外壳；
- 元件高度和装配方向；
- 连接器插拔空间；
- 螺丝、支柱和外壳受力；
- 返修和探针访问；
- 声孔、光路、气流和天线区域。

空白区域可以服务于天线、声学、散热、装配或布线。

## 更新项目主文稿

把稳定 PCB 结论写入 3.x 章节：

- 板框和机械条件；
- 功能分区和器件关系；
- 网络分类、线宽和过孔策略；
- 关键拓扑和回流；
- keepout、散热和装配要求；
- 当前布局、布线、铺铜和 DRC 状态；
- 当前 PCB 源文件。

不复制完整几何和 DRC 输出。

## 完成本阶段

进入制造准备前确认：

- PCB 源文件已经保存；
- 主要器件、板框、孔和接口位置正确；
- 所有需要连接的网络已经布通；
- 关键电源、信号和返回路径符合当前设计；
- 实际铺铜已经更新；
- 引脚调整已经同步；
- DRC 没有未解释的当前问题；
- 机械、装配、测试和散热条件已经检查；
- 主文稿的 3.x 章节和顶部当前交接已经更新。

Gerber、钻孔、BOM、CPL 和板厂预览在 [4.1-production-handoff.md](4.1-production-handoff.md) 中处理。
