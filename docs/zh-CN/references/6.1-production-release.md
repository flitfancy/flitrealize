# 6.1 产品化与正式发布

只有用户明确要求重复生产、批量 PCBA、可复现交付或正式发布时，才读取本参考。

普通个人原型完成实物验证后即可根据测量结果改版，不需要额外维护发布流程。

## 明确发布目标

先说明本次准备支持什么：

- 重复生产同一硬件版本；
- 委托 PCBA；
- 对外提供制造文件；
- 建立正式产品版本；
- 满足项目适用的法规、追溯或质量要求。

只增加当前发布目标真正需要的工作，不要求所有项目采用相同形式。

## 固定当前版本

正式候选应能够把以下内容对应到同一版本：

- 需求和设计决策；
- 原理图与 PCB 源文件；
- BOM 和允许替代；
- Gerber、钻孔和装配文件；
- 固件或配置依赖；
- 样机验证结果；
- 生产测试或校准方法。

制造文件的准备、核对和归档见 [4.1-production-handoff.md](4.1-production-handoff.md)。

## 处理重复生产需要的问题

根据产品实际情况确认：

- 关键器件是否能够持续采购；
- 长期替代器件的范围和验证条件；
- 生产中怎样识别版本；
- 上电、功能和接口怎样测试；
- 是否需要校准、序列号或测试记录；
- 外壳、线束和装配方式是否固定；
- 维修、返工或失效品怎样处理。

已经通过的一块样机只能证明对应样机和测试条件，不能自动证明后续批次无需生产测试。

## 法规和专业评审

涉及市电、高压、电池安全、医疗、无线认证或其他受监管用途时，核对当前适用标准，并取得项目实际需要的专业评审和测试。

本 Skill 可以整理设计和证据，但不能替代法规认证或签字责任。

## 发布结论

使用直接语言记录：

- 当前发布对象和版本；
- 已有的实物和生产证据；
- 真正阻塞发布的问题；
- 已接受的限制；
- 仍需完成的生产测试、认证或供应工作；
- 下一步动作。

结论只覆盖当前声明的发布目标。不创建不会改变发布判断的状态表、阶段文书或证据标签。
