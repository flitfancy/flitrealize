# 0.4 EasyEDA Pro 环境与连接

首次在当前主机使用 EasyEDA Pro、连接已经中断，或需要确认当前执行通道时读取本参考。

本流程只负责建立可用连接并确认目标文档。原理图和 PCB 的具体操作由对应阶段流程处理。

## 建立连接

本机 Adapter 只需要注册一次：

```text
node <skill>/scripts/eda-host.mjs register \
  --eda easyeda-pro \
  --adapter-root <adapter-root>
```

已经注册时不要重复注册，直接建立或复用当前连接：

```text
node <skill>/scripts/eda-host.mjs ensure \
  --eda easyeda-pro \
  --require-eda
```

Adapter 安装路径保存在本机配置中，不写入项目 Contract，也不复制到可移植 Skill 文档。

只有尚未注册，并且无法从当前主机配置确定 Adapter 位置时，才需要用户提供准确路径。

## 确认当前目标

开始 EDA 操作前确认：

- EasyEDA Pro 已经连接；
- 当前窗口和项目正确；
- 当前文档类型符合任务；
- 原理图或 PCB 文档是本次准备修改的目标；
- 下一步需要的 Action 或 API 能力可用。

只检查当前操作需要的能力，不遍历全部 EasyEDA API。

如果项目已经声明预期 EDA 或文档身份，应与当前连接比较。发现连接到了其他项目或文档时，先切换到正确目标，不继续写入。

## 复用当前连接

以下条件没有变化时，可以在当前任务中继续复用连接：

- EasyEDA 没有重启或断开；
- Bridge 和 Adapter 仍然可达；
- 当前项目和目标文档没有切换；
- 下一步所需能力仍然可用。

不需要在每轮聊天或每个小操作前重新注册和建立连接。

切换窗口、项目或文档后，应重新确认当前目标。文档经过手工修改时不一定需要重连，但后续工作流必须重新读取实际文档状态。

## 处理连接失败

连接失败时，按观察到的状态检查：

1. EasyEDA Pro 是否正在运行；
2. Adapter 是否已经注册且路径有效；
3. Bridge 是否能够启动或复用；
4. EasyEDA 网关是否已经连接；
5. 当前窗口和文档是否可识别；
6. 当前操作需要的能力是否存在。

根据实际失败点执行一次有针对性的恢复，例如启动 Bridge、重新连接网关、重新选择窗口或重新读取文档。

恢复后重新检查结果。没有新证据时，不重复执行相同的重连动作。

仍然无法连接时，报告：

- 已经成功到达的层；
- 实际失败位置；
- 当前观察到的错误；
- 用户需要完成的最小操作。

连接问题只阻止依赖实时 EDA 的操作，不影响需求、器件选择、Contract 或其他离线设计工作继续进行。
