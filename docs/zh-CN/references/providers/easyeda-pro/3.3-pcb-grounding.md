# 3.3 EasyEDA Pro PCB 回流与接地

参考铜已经建立，需要检查局部回流、信号换层参考、散热接地或按需增加接地过孔时读取本参考。

本流程的目标是闭合实际电流和信号回路。接地过孔数量、规则网格和板边围栏本身都不是目标。

```text
读取实际铜和布线
    → 识别必要回流
    → 放置并验证必要过孔
    → 按需优化屏蔽或全局连接
    → 重铺、检查并保存
```

## 确认当前输入

开始前确认：

- 当前项目和目标 PCB 文档；
- 已经实际生成的参考铜；
- 当前布局、走线、换层和过孔；
- 目标接地网络；
- 过孔尺寸和制造间距；
- 板框、孔、焊盘、走线和 keepout；
- 需要检查的功率、敏感信号、ESD、散热或屏蔽区域。

如果布线仍会大范围变化，先完成当前关键路径，再处理相应回流。没有实际信号路径时，不提前生成大量推测性接地过孔。

## 使用现有 Action

当前相关 Action 包括：

- `pcb-grounding-inspect`：读取当前铺铜、Region、过孔和相关器件；
- `pcb-ground-vias`：规划、写入和验证范围明确的接地过孔；
- `pcb-ground-stitching`：为换层回流、平面连接或板边屏蔽生成候选。

实际能力以当前 Action manifest、能力探测和运行结果为准。规划结果不能代替写入和回读；自动化无法处理的局部几何可以在 EasyEDA 中完成，并对实际结果进行验证。

## 1. 检查实际回流

结合当前铺铜和布线检查：

- 去耦电容到器件电源与地引脚的回路；
- 开关电源输入、输出和功率器件回路；
- 裸露焊盘、功率器件和散热路径；
- ESD、TVS 和接口保护的泄放路径；
- 信号换层后的参考平面变化；
- 高速、时钟、模拟和其他敏感信号的连续参考；
- keepout、槽、平面分割和狭窄铜区造成的回流绕行；
- 不同地铜区域之间是否真正连接。

重点判断电流从哪里出发、经过什么负载、怎样返回。网络都叫 GND 不能证明实际铜皮连续，器件附近存在过孔也不能证明它位于有效回流路径中。

## 2. 放置必要接地过孔

优先处理能够解决明确问题的过孔：

- 去耦和局部电源回路；
- 功率器件与散热焊盘；
- ESD 和接口保护；
- 信号换层附近的参考地；
- 被层转换或局部几何打断的返回路径；
- 当前设计明确要求的机壳地或屏蔽连接。

每组过孔应具有清楚的对象和目的。放置时检查：

- 实际网络；
- 锚点和位置；
- 目标层是否存在可连接铜；
- 与焊盘、走线、孔、板边和 keepout 的间距；
- 孔径、外径和制造能力；
- 是否影响器件焊接、钢网、返修或机械安装。

靠近器件只是候选条件，不自动证明该过孔必要或有效。没有目标铜、被 keepout 隔断，或落在无效孤岛中的过孔不能闭合回流。

写入后按实际对象 ID 或准确几何回读新增过孔，确认网络、位置、尺寸和数量符合本次请求，并且没有改变原有过孔。

## 3. 重新铺铜并验证

增加或移动接地过孔后：

1. 重新铺受影响的铜；
2. 检查过孔是否实际连接到目标铜；
3. 检查回流路径是否比修改前更直接；
4. 查看是否产生孤岛、细颈或意外间距；
5. 运行当前项目配置的 DRC；
6. 目检关键功率、换层、ESD 和敏感区域；
7. 保存并再次读取结果。

第一次写入成功只证明对象已经创建，不证明回流问题已经解决。

## 4. 按需进行全局优化

必要局部回流完成后，只有设计确实需要时才考虑：

- 多层地平面之间的连接；
- 稀疏区域的参考补强；
- RF、EMC 或屏蔽需要的板边围栏；
- 特定接口或信号换层区域的附加回流；
- 大面积散热和电流分布。

全局优化应有明确目的和停止条件。不默认铺满规则地孔网格，也不为了达到某个数量而继续增加过孔。

规划器可以帮助发现候选，但候选仍需结合实际铜、间距、机械区域和制造能力筛选。只有能够改善当前回流、屏蔽、散热或平面连接的候选才写入。

无法安全放置的局部区域可以保持为已知限制，不通过缩小间距或绕过 keepout 强行填充。

## 失败与恢复

按 [0.3 EasyEDA Pro Provider](../../0.3-easyeda-pro.md) 重新读取现场后再处理。接地恢复只补齐或撤销本次能够准确识别的过孔和相关铜对象，不复用已经过期的坐标或几何结果。

某个特殊几何无法自动判断时，只暂停受影响区域并进行局部人工检查或实际回读。如果制造间距、连通、keepout 或目标铜仍无法确认，应在 PCB 阶段解决；只有必须依赖实物行为才能判断的功能问题才转为样机测试。

## 完成本阶段

完成接地处理后确认：

- 必要的局部功率和去耦回路已经闭合；
- 信号换层具有合理参考回流；
- ESD、散热和屏蔽连接符合当前设计；
- 新增过孔实际连接到目标铜；
- 铺铜已经更新；
- 没有明显孤岛、狭窄通道或意外断开；
- DRC 没有未解释的当前问题；
- PCB 已保存。

完成后返回 [3.1 PCB 设计与检查](../../3.1-pcb-review.md) 进行整板检查。只有 3.1 的出口条件满足后，才进入 [4.1 制造文件与原型下单](../../4.1-production-handoff.md)。
