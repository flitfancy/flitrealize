# 3.2 EasyEDA Pro PCB 基础实现

已经在 [3.1 PCB 设计与检查](../../3.1-pcb-review.md) 中确定 PCB 基础方案，需要在 EasyEDA Pro 中建立或修改层、板框、功能性 keepout 和参考铜时读取本参考。

本流程只负责落实当前 PCB 的物理基础。布局、布线和网络规则由 3.1 决定；回流与接地过孔见 [3.3 PCB 回流与接地](3.3-pcb-grounding.md)。

需要时分两次进入本流程：

```text
第一次：读取 PCB → 建立层和板框 → 落实功能性 keepout
布局和关键布线后：创建或重铺参考铜 → 检查并保存
```

## 确认当前输入

开始写入前确认：

- 当前项目和目标 PCB 文档；
- 当前板框、安装孔和机械接口；
- 已选择的铜层数量及每层作用；
- 重要信号使用的参考层；
- 需要落实的功能性 keepout；
- 需要创建或保留的平面与铺铜网络；
- 已有布局、布线、过孔和铺铜中需要保留的内容；
- 当前板厂能力或本阶段采用的明确假设。

适用项可以是已确认、暂定或明确不适用。只有缺口会让当前修改无法落地，或可能覆盖已有重要内容时，才停止受影响操作；其余工作可以继续。

## 使用现有 Action

当前相关 Action 包括：

- `pcb-layer-stack`：读取和修改逻辑铜层结构；
- `pcb-component-geometry`：读取器件、焊盘和封装几何；
- `pcb-functional-keepouts`：读取和修改有明确用途的 keepout；
- `pcb-ground-pours`：读取和修改有边界的参考铜。

实际能力以当前 Action manifest、能力探测和运行结果为准。现有 Action 不能完成的局部操作，可以使用 EasyEDA 当前可用的方法完成，并在写入后回读验证。

## 1. 读取当前 PCB

修改前读取与本次工作有关的实际对象：

- 板框和开槽；
- 铜层及顺序；
- 器件、焊盘和安装孔；
- 已有走线、过孔和平面；
- keepout 和其他 Region；
- 当前保存状态。

画布外观可以帮助理解，但不能代替对象身份、层、网络和几何回读。

如果 PCB 已经存在手工布局或布线，先确认本次修改会影响哪些对象，不通过重新生成整个基础结构覆盖已有工作。

## 2. 建立层和板框

按照 3.1 已经选择的方案设置：

- 铜层数量和顺序；
- 每层主要作用；
- 参考层和平面网络；
- 板框、槽和必要机械边界；
- 安装孔和边缘接口位置。

逻辑层名称或平面网络设置不能证明实际铜已经存在。物理介质厚度、铜厚和阻抗参数仍应来自当前板厂能力或项目假设。

增加层通常可以作为局部修改处理。减少层、改变已有层用途，或移动已经承载铜和器件的板框，可能删除或破坏现有内容；发现这种实际冲突时，先确认受影响对象和处理方法，再继续执行。

写入后回读层顺序、板框和关键机械对象，确认没有意外移除已有内容。

## 3. 落实功能性 keepout

只为明确的工程目的创建 keepout，例如：

- 天线净空；
- 麦克风、压力、光学或气流开口；
- 电气隔离；
- 安装和机械活动空间；
- 厂商明确规定的禁铜区域；
- 需要限制器件、走线、过孔或铺铜的区域。

为每个 keepout 明确：

- 作用；
- 来源；
- 几何边界；
- 影响的层和对象类型；
- 是否允许必要的局部例外。

丝印外框、庭院层或视觉空白不自动等于铜 keepout。需要从实际器件、封装或机械几何确认边界。

写入后回读新增 Region 的层、规则和几何，并检查它没有覆盖焊盘、板框、必要走线或其他受保护对象。

## 4. 创建参考铜

布局和关键布线完成后再执行本节，使实际铜形状和回流通道能够结合真实几何检查。

板框和功能性 keepout 清楚后，创建当前设计需要的平面或铺铜。

确认：

- 目标网络；
- 所在层；
- 铺铜边界；
- 与板边、孔、焊盘和其他网络的间距；
- keepout 是否实际生效；
- 热焊盘或直连方式；
- 需要保留的开槽、分区和回流通道。

铺铜边界存在不代表铜已经成功生成。创建或修改后必须重新铺铜，并检查实际填充、孤岛、狭窄通道、意外断开以及关键区域的净空。

复杂板卡可以先在一个代表层或区域完成检查，再扩展到其他层。某个特殊几何无法解析时，只暂停受影响区域，不把未相关的整块 PCB 一起阻塞。

## 5. 检查并保存

完成当前基础增量后：

1. 重新铺受影响的铜；
2. 回读新增或修改的层、Region 和铺铜；
3. 检查板框、机械对象和原有内容是否保持；
4. 目检关键 keepout 和实际铜形状；
5. 运行当前项目配置的 DRC；
6. 保存 PCB；
7. 确认保存后的文档仍包含本次结果。

DRC 只能检查当前规则能够识别的问题。参考铜是否为关键网络提供了合理回流，还需要结合实际布局和布线判断。

## 失败与恢复

按 [0.3 EasyEDA Pro Provider](../../0.3-easyeda-pro.md) 重新读取现场后再处理。PCB 基础恢复只补齐或撤销本次能够准确识别的层、板框、Region 和铺铜对象。

## 完成第一次进入

返回 3.1 继续布局和关键布线前确认：

- 铜层顺序和作用与当前设计一致；
- 板框、安装孔和主要机械接口正确；
- 功能性 keepout 已经落实并回读。

返回 [3.1 PCB 设计与检查](../../3.1-pcb-review.md) 完成布局和关键布线。

## 完成参考铜

布局和关键布线后回到本流程，并确认：

- 需要的参考铜已经实际生成；
- 关键区域没有明显孤岛、断开或错误净空；
- PCB 已保存且没有未解释的当前 DRC 问题。

随后读取 [3.3 PCB 回流与接地](3.3-pcb-grounding.md)。
