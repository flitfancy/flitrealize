# PCB 布局、布线与制造评审

处理布局、布线、平面、已配置 DRC 或 Gerber/钻孔评审时读取本参考。

## 建立布局意图

选择与请求匹配的模式：

- **拓扑图：**明确功能组及 must-near/keep-away 关系；
- **紧凑候选：**在不破坏拓扑、访问和布线通道的前提下追求指定外形；
- **保留手工：**冻结用户已接受工作，只做明确局部增量。

记录外形目标是硬约束还是期望，并记录锚点、边缘接口、功能组、关键关系、keepout/噪声/RF/声学/机械区域和目视验收标准。区分天线、声学、散热、装配和布线所需空白与浪费。

完整布局前验证一个关键功能块和整体分区图。离线零碰撞是 `automated-green`；真实封装几何和目视/3D 接受证明不同事实。

## 按关系布局，不按装饰对齐

先检查功能流：

- 连接器 -> 保护 -> 受保护电路；
- 稳压器输入/输出和开关环路；
- 本地旁路、晶振/参考/反馈路径；
- 大电流/热/噪声与敏感模块隔离；
- 传感器开口、气流、光路、污染和热隔离；
- 插拔、安装、高度、返修、测试和装配访问。

密集或特殊封装使用铜/焊盘几何和元件本体。方向使用插口、受保护侧、pin-1/网络契约、端口视场等语义表达，不固定成一个板边角度。可复用方向逻辑应允许整组合法旋转，并拒绝单器件反转、错误封装身份和被阻挡的访问通道。

## 从明确契约开始布线

布线前，在机器契约或选定总览中记录网络类、标称/最小线宽、间距、过孔/层策略、拓扑、回流要求和有序关键路径。每次布线并验证一个风险类。

检查：

- 主/支路电源瓶颈、缩颈长度、过孔容量和回流阻抗；
- 关键拓扑、stub、换层、耦合和连续回流；
- 地铺铜、孤岛、狭窄通道、分割和局部缝合；
- ESD 路径与环路面积；
- 热焊盘、环宽、阻焊桥、孔/板边、极性、丝印和装配访问。

把宽主干与允许的焊盘逃逸分开。焊盘无法容纳主干时，记录逃逸线宽、最大缩颈长度、过渡点和过孔策略。全局制造最小值不定义每条功能走线。

导入规则时分别验证规则定义和实际网络分配。制造最小值、命名网络类规则和交互默认值保持独立。关键电源、保护、时钟/高速、反馈和传感路径手工布线；自动布线只用于有边界的剩余网络，随后按拓扑和网络类审查。

## 把环境视为 PCB 的一部分

只应用相关约束：环境传感器热/气流隔离，压力/声学/光学端口无遮挡，VOC/NOx 区域防污染，本地峰值电流旁路，RF keepout 和外壳/机械应力。对必要电气 fanout 明确定义例外，不把每个空白区都当成绝对禁铜区。

## 正确解释证据

干净的已配置 DRC 只证明规则符合，不证明引脚、BOM、电源完整性、EMC/ESD、散热、外壳或可靠性。必须审查规则集。截图证明视觉属性，不证明连通性或精确间距。数值几何和目视接受互补，不能互相替代。

## 交叉检查制造输出

把已识别源/导出版本配对，并按适用范围检查：

- 闭合板框和尺寸；
- 铜、阻焊、钢网、丝印、机械和钻孔层；
- PTH/NPTH 刀具、槽、数量和直径；
- 从源/capture 得到的预期布线连通性；
- 顶/底元件与钢网/装配输出；
- 铺铜、keepout、盖油、极性、文字和底面方向；
- 所选板厂的当前预览和能力。

Gerber 没有元件/网络语义。身份与连通使用源/capture，视觉使用渲染合成图，制造事实使用能证明它们的数值检查。
