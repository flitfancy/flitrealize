# 原型上电与证据驱动改版

首次上电、子系统测试、筛选和改版决策时读取本参考。

## 按比例准备

上电前记录预期电源轨/电流、启动状态、测试顺序、限制和停止条件。按风险选择仪器：限流电源和万用表是最低配置；示波器/逻辑分析仪和自动日志只在能区分合理故障时使用。

可行时制作多块原型并保留一块未修改板。分阶段装配中，昂贵、脆弱或高能量负载只有在前置条件通过后再装。记录已装器件、返修、测量和板卡身份，使结果可归因。

## 安全上电

1. 检查极性/方向、锡桥、碎屑、开口和连接器。
2. 测量各电源轨未上电对地电阻。
3. 使用保守限流上电。
4. 启用负载前验证受保护输入和稳压电源轨。
5. 逐个启用子系统并记录电流变化。
6. 测试真实负载，同时观察压降、纹波、启动和温度。

限制值来自当前设计，不能复制其他板卡数值。

## 测试定义成功的功能

按适用范围测试总线、ID/状态、复位、中断、GPIO、负载、恢复和上下电。记录原始值、错误、电源状态、固件版本、板卡序列号和时间戳。测试可信故障但不超过额定值。

稳定性时长和重复次数由验收目标与故障时间尺度决定。早期个人原型可能只需短测试；只有长期稳定性属于当前主张时，才运行 24–72 小时日志。

## 筛选传感器但不虚构校准

区分：

- 厂商出厂校准；
- 装配后损伤、污染、偏移、噪声和响应筛选；
- 对稳定外壳/板级影响的系统补偿；
- 对具有已知不确定度标准的可追溯校准。

按需比较偏移、噪声、漂移、重复性、响应/恢复、迟滞、上下电、温度和多块板差异。稳定固定偏移可以补偿；过大噪声、漂移、迟滞或慢响应需要调查。使用受控安全刺激，不把呼吸、喷雾、阳光或环境条件当绝对参考。

## 从可复现证据改版

每个实质失败记录板卡版本/序列号、环境、复现、测量/波形、怀疑领域、拟议变化和预期可测效果。

- **P1：**有证据支持的高价值修正；
- **P2：**需求取决于更多测试的改进；
- **P3：**需要明确用途或故障模型的复杂功能。

不要仅为视觉布线偏好、理论完整、不可复现行为或推测性功能创建硬件新版本。
