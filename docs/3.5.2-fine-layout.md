# 3.5.2 块内布局

功能块布局或人工调整已确定块的大致位置，需要安排块内簇和器件时读取。块是承担一项功能的部分；簇是块内联系紧密的器件集合。本轮可以处理一个簇、相邻簇或整个块，范围先说明。目标是落实块内电气关系和跨块连接，兼顾局部疏密、装配与位号；已认可的整体结构继续作为基线。

[功能块布局](3.5.1-block-layout.md#三交出什么)交出块的区域、机械锚点、跨块连接和允许变化范围；块内布局安排簇与器件的位置和朝向；[走线](3.1-pcb-review.md#走线与局部反馈)连接网络并把失败证据反馈给局部调整。层级是工作分工，不把簇默认当作内部位置不能改变的刚性模板。

## 输入与范围

以最新 PCB 和上游设计为权威来源，复用 [3.3.2 块内布局输入与转置](3.3.2-fine-layout-inputs.md)及准备回执。下面是本轮输入清单，不是新增的配置格式：

| 输入 | 需要明确的内容 |
| --- | --- |
| 当前现场 | 项目/PCB 身份、源指纹、器件/封装/焊盘/网络、位置与角度、位号、板框、锁定及已有铜；旧候选不能覆盖期间的人工修改 |
| 所选功能区 | 复用电路设计稿的块名和成员位号；给出本轮区域、边界来源、预留用途及允许变化的范围；功能块归属本身不生成区域硬约束 |
| 所选簇 | 说明簇属于哪个块、包含哪些器件及其关键关系；可复用已有局部分组，不能假定已有分组字段自动表达完整层级或区域约束 |
| 固定与可转器件 | 明确机械锚点、必须保持的姿态及许可旋转；块内主芯片和电感可按电气依据参与重排，不按位号前缀一律固定；原生锁和机械锁继续保留 |
| 外部环境 | 范围外器件、位号、预留区及障碍；跨块网络的实际焊盘端点、接口方向和出口要求；从完整网表推导，不只裁出块内连接 |
| 可让位邻居 | 需要腾出目标区域时，列出允许调整的邻居及其范围和固定条件；不因邻居挡路就默认纳入整板重排 |
| 电气与机械规则 | 复用显式电气关系、网络角色、板框/禁区、装配和操作空间、位号规则；具体距离、线宽和间距记录来源或明确的项目假设 |
| 本轮预算 | 需要比较的分项、候选数量、时间/尝试预算及停止条件；搜索设置不是制造要求 |

先核对身份、引脚映射、区域与规则的一致性。阻止当前建模或可能推翻关键关系的缺项先解决；其他缺项列为未覆盖。没有数值依据时，不从网名、用途文字或旧试排坐标编造阈值；可先出受限预览，不能把未知要求标为通过。

请求中的成员、固定条件、关系与位号权限见[块内布局输入与权限](../schemas/pcb-layout.md#块内布局输入与权限)，基础规则与本轮变化的合成见[共用输入说明](../schemas/pcb-layout.md#基础规则与本轮变化)。生成、接入和应用已有候选，以及计时和可选前后图的用法见[块内布局执行接口](technical/pcb-fine-layout-execution.md)。

## 安排与边界

重排只放开明确成员和允许让位邻居，保留外部真实障碍、跨块焊盘及锁来源；簇不默认刚体。

工作区域应说明来源。可沿用明确窗口，也可在授权下使用真实板框内全部建模空白，不把原包络外扩自动当作硬边界；空白仍受层、边缘、固定障碍、装配、来源约束及预留限制。不会因搜索失败自动扩大邻居权限。

每条硬条件与比较条件均须有依据且显式声明，旧距离不自动变为安全上限；软目标及所有距离变化逐项报告，总分改善不能抵消单项拒绝。局部通过、局部写回资格、整板资格、离线试走线和保存回读分别记录。范围内及跨块影响须检查；显式允许保留基线旧问题时，按同一规则、对象身份与关系逐条重算，已消失或可证明未加重的旧问题可保留。新问题、加重问题、本轮明确要求修复却未满足的问题，以及身份或几何证据不足的问题仍阻断。`require-clean` 与既有显式关系、区域及预留区要求保持严格；原生预检与保存回读复用共同分类器，但不声称原生覆盖全部离线检查。

参与对象完全未变可作为快速证明；移动或旋转后的旧问题使用[逐问题几何非加重比较](technical/pcb-fine-layout-execution.md#输入与权限)，不再设半转特例。间距、各轴重叠及侵入深度分别核对，具体焊盘身份、编号、网络和规则阈值均保持；较小面积、较少问题或较好总分不能掩盖另一项恶化。固定外部违规留在报告，只有完整依赖均固定且旧失败已有证明时才从求解约束分区排除；活动区域所有者、活动标签和跨范围端点仍执行。

调用布局或移动入口前，必须核对 [块内布局复用能力与已有铜](providers/easyeda-pro/3.5-r-pcb-placement.md#块内布局复用能力与已有铜)及所用后端的支持条件。已有铜的拒绝范围、允许处理方式和绕过限制的禁止项由该页维护；不能满足时保留只读分析或改用适合的工具。

## 局部重排与反馈

1. **建立基线。**记录本块及边界的关键关系、拥挤/空白和位号问题，确定本轮块、簇和成员、区域、固定件及可让位邻居。需要预占位时先检查目标区域被哪些对象占用。
2. **在边界内比较少量候选。**保留范围外姿态及障碍，允许有依据地移动/旋转块内主器件和外围；器件与位号协同。裁剪范围时仍须保留外部环境和跨块端点；无板框开放块结果不能代替区域内整板检查。
3. **先检查关键关系，再比较疏密。**去耦、功率、采样、保护和其他已声明关系逐条审阅，照顾真实焊盘方向与跨块出口。疏密是软目标，关键局部可合理密集；不为了填空或均匀而拉散回路。
4. **按需检查出口并试走关键网。**先看焊盘出口、邻脚竞争和跨块边界，再使用相同候选版本与明确网络／规则做有限试走，保留外部障碍并独立验收。记录失败网络、端点、出口／通道、已知阻挡器件或铜对象及证据；未知位置保留，有限搜索失败不等于几何无解。AI 据此提出最小移动范围，再由已有工具生成和核验局部候选。需要潜在地空间比较时见[布局诊断](technical/pcb-ground-space.md)；输入和模式只在[离线试走线技术参考](technical/pcb-prerouting.md)维护，不要求每个候选整板走通，也不自动扩大范围或清板重走。
5. **处理区域不足。**报告需要的空间、挡路对象和受影响跨块关系；先在已允许的邻居范围内让位。仍不足时退回相关功能块布局边界调整，或请求明确扩大范围，不自行扩大板框或移动固定件。没有统一毫米数、网格或所有主器件固定的默认规则。

## 输出、验收与停止

结果应列出所选功能块的完整成员、本轮参与调整的成员，以及未参与成员和原因。仅调整部分成员时，明确说明本轮范围。

输出少量有稳定 ID 和来源指纹的候选及前后摆放图，说明块、簇与成员对应关系，列出实际移动/旋转的成员、邻居与位号；逐项报告关键焊盘关系、跨块连接代理、疏密、装配/几何和丝印变化，以及退化、失败和未覆盖项。完整坐标和网表保留在原制品/派生报告中。独立标明候选、已写入、已保存回读和试走线的状态。

接受候选前检查：

- 范围外对象及固定条件保持；器件身份、焊盘归属、网络和板框没有意外变化。
- 已声明的基础／本轮硬条件和显式非退化条件必须逐条满足，不能用总分抵消拒绝项。其他软目标变化分别报告，由工程判断取舍；旧布局本身不自动是安全上限。标为关键但没有验收条件的关系仍属未覆盖，不能当作已通过。
- 本块及受影响边界的板内占位、装配、禁区和位号符合已声明规则；未纳入模型的条件保留待验，既有范围外问题不被本轮局部通过掩盖。
- 对适用的关键出口/跨块连接完成声明范围的试走线与独立验收；未做或工具不覆盖时明确保留，不宣称可布通。距离代理不等同实际回路、回流或电气性能合格。
- 应用只使用与最新现场绑定的完整受支持计划，按现有入口核对实际变化、原生检查、保存与回读；选中少量成员不代表可以省略其他对象的保持核验。

应用与恢复使用[块内布局执行接口](technical/pcb-fine-layout-execution.md)，失败处理遵循[共同执行规则](0.3-easyeda-pro.md#失败与恢复)。

获得满足本轮要求的有效候选并完成相应核验后停止；达到搜索预算或连续尝试无有效改善时也停止，交付最佳已验候选或具体阻塞原因，不把不合格候选写成完成。预算耗尽、区域不足、规则冲突和能力不支持分别报告；效果仍不满足才明确下一轮目标与范围。均匀、无碰撞或代理分数降低均不等于已布通或可制造。

稳定结果按[项目主文稿](0.1-continuation.md)同步本次布局主题，保留范围、理由、回读证据和未决项。
