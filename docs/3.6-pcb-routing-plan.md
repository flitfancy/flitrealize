# 3.6 PCB 布线规则与优先级

整理网络分类、宽度与布线顺序，或从已有规则派生改宽／配色输入时读取。本页维护规则来源、执行顺序与交接，设计依据见 [3.1 PCB 设计](3.1-pcb-review.md)。

## 输入与规则来源

已有 PCB 规则配置作为源时，配色输入为派生产物；分类变化后重新生成，不独立编辑第二套成员。输入、网络分类、宽度、排序及覆盖语义见[网络规则数据约定](../schemas/pcb-routing.md#网络规则规划输入)。

## 规划与执行

后续执行者按序完成关键组，回读拓扑、线宽、连接和 DRC，再继续普通网络；交接中留相应证据。**有序计划不等于自动布线器执行顺序已设置**。

本地规划、派生请求的命令、读取位置和支持限制见[网络规则工具参考](technical/pcb-prerouting.md#网络规则规划)。实际配色、指定线段改宽与自动走线分别见 [3.4-r](providers/easyeda-pro/3.4-r-pcb-net-color.md)、[3.8-r](providers/easyeda-pro/3.8-r-pcb-trace-width.md)和 [3.8-r](providers/easyeda-pro/3.8-r-pcb-autorouting.md)。

## 同步项目交接

在主文稿“网络规则”的“布线规则与优先级”小节记录网络分类及用途、线宽／过孔依据、执行顺序和权威规则配置；派生输入引用对应来源版本。生成计划仍标 planned，不写成已经布线、改宽或配色。按 [0.1 项目主文稿](0.1-continuation.md#pcb-主题与面板对应)同步网络汇总表中受影响的行、该主题的 `ViewState:` 和顶部交接，注明表中数值的来源与计划／实际状态；保留改宽和配色的独立执行证据。
