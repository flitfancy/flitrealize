# 3.2 板框、层叠与禁区

拿到已核对的 PCB 基线，在布局前落实本轮物理条件。实际参考铜在走线后的 [3.9.1](3.9.1-pcb-ground-pours.md)建立，回流与必要地孔见 [3.9.2](3.9.2-pcb-grounding.md)。

## 输入

复用当前板框、安装孔、机械接口，已选择的铜层数量、层作用和重要网络参考层，以及功能性禁区、已有布局与铜的保留范围。制造介质厚度、铜厚和阻抗依据来自板厂能力或明确的项目假设；适用项可为已确认、暂定或明确不适用。只暂停无法落地或会影响已有重要内容的部分。

## 处理

1. 核对板框、槽、安装孔和接口方向，落实层数量、顺序、用途及参考网络。逻辑层或平面网络设置不能证明实际铜已生成。
2. 减少层、改变已有层用途或移动载有铜和器件的板框时，先明确受影响对象与处理方法；保留已有手工布局、布线和机械要求。
3. 按明确用途落实禁区：天线、声孔、压力／光学／气流开口、电气隔离、机械活动及厂商禁铜要求。每个禁区注明作用、来源、边界、层、限制的对象类型和必要例外；丝印外框、庭院或视觉空白不自动是铜禁区。
4. 核对层顺序、板框、机械对象及禁区的实际范围。若影响已有铜，维护并核对受影响部分；这不要求布局前创建新的参考铜。

软件操作和支持边界见 [3.2-r EasyEDA 实现](providers/easyeda-pro/3.2-r-pcb-foundation.md)，共同现场执行与保存判断见 [0.3](0.3-easyeda-pro.md)。

## 产物

交出本轮板框与机械边界、层用途、功能性禁区、制造依据、检查结果和未决项。实际修改的保存与回读状态单独记录，完整几何留在源设计和原始报告。

## 进入下一步

物理条件可用于本轮布局，层与机械条件一致，禁区已核对，实际修改已检查并保存后，进入 [3.3 布局输入与规则转置](3.3-pcb-layout-inputs.md)。纯核对只说明已查范围，不附带现场修改。
