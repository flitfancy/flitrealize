## 先找实际入口

```text
node <skill>/scripts/action-runner.mjs list --domain schematic --query "原理图重排"
node <skill>/scripts/action-runner.mjs list --domain pcb --query "线宽"
```

`list` 只读本地 manifest，不连接 Bridge、不执行 Action、不创建报告。先提取用途短词；空格分开的词须全部匹配，英文不区分大小写。查询未命中时核对用词，必要时看一次本阶段 `--full`，再检查本项目已有脚本；未命中不代表任务无法完成。

按结果中的 `entrypoint.kind` 调用：

- `script`：优先使用已有薄封装，负责衔接步骤和保留报告。
- `action-runner`：使用列出的脚本、参数及本次输入。
- `workflow-steps`：是步骤说明，不是可直接运行的命令。

`reference` 和 `entrypoint.file` 相对于 Skill 根目录；Action 的 `file` 相对于 `scripts/actions/`。先看 `limitations` 和 `modes`，不要把原理图导线颜色当成 PCB 配色。没有适用封装时，单独调用 Action：

```text
node <skill>/scripts/action-runner.mjs run --action <name> --input-file <input.json> --project-root <项目> --window-id <窗口> --report-file <稳定证据路径>
```

写入另需 `--allow-write`。参数体现用户当前授权，不要求用户重复批准已明确的操作，也不因发现脚本扩大授权。现有工具未覆盖的部分可用当前可用 API 或其他合适方法完成；未经验证的方法不登记为稳定能力。修改实现时再读 [Action 开发](../development/action-system.md)。

需要原生 API 时按本机 Adapter 的入口定向查询；已提供 `scripts/api-reference.mjs search/show` 的 Adapter 可离线取出候选与完整成员说明。已有 Action 正常使用不额外查底层资料；查询不可用时仍可检索原文，不强制升级、审计或重连。

## 现场边界与验证

操作前确认目标项目、文档类型、受影响对象和预期结果。身份、引脚、网络、层和几何来自实际源文件或结构化回读；画布用于视觉检查，不能替代对象身份。

写入通常按 `读取 → 计划 → 修改 → 回读 → 保存 → 保存后核对`。同类批量先验证一个代表对象，范围外内容保留。保存必须有独立证据；只读检查和计划不要求产生修改或保存。

手工修改、重开文档或中断后先刷新现场，再判断旧计划是否仍适用。执行期间避免第二个写入者；会修改或清理对象的步骤应再次核对目标与对象归属。单次起始检查不等于整次操作安全。

## 失败与恢复

失败、超时或返回不明时先读报告，再只读核对现场；没有成功回执不等于没有写入。报告可把通信结果标成 unknown，不能据此重放写入。

报告有 Bridge 请求句柄时，可通过 [环境入口的请求查询](providers/easyeda-pro/0.4-environment.md#查询中断的请求) 取回迟到结果。查询不执行原代码，也不自动改写旧报告或解除工作流占用；终态仍须与原输入和现场对账。

- 已确认部分结果：按 ID、输入版本和回读证据补齐必要增量，不覆盖用户手改。
- 仅保存失败：现场仍匹配时只恢复保存，不重新执行修改。
- 撤销：只处理能证明由本次创建的对象。无 ID、重复/原有 ID 或目标变化时，不猜归属、不盲删；无法证明恢复完整就不能报告 rolled-back。
- 未知或仍在执行的写入：先取得确定终态，不能换新批次绕过。各入口的续接/关闭能力以阶段文档为准。

备份用于对账和有范围的恢复，不自动整图覆盖后续修改。原因明确的一次失败修正后继续；需要反复观察时，只对该问题进入 [0.2 聚焦调试](0.2-debug-loop.md)。连接问题不阻止不依赖实时 EDA 的离线设计。

## 本次完成与导出

按用户本次范围结束：只读任务交付所查事实和限制；写入任务核对目标增量、原有内容保留及保存结果。分别说明保存、对象回读、连接、DRC 和电气审查，不能用一个成功状态代替全部验收。稳定结论写回同一份主文稿的相应章节。

制造输出的版本配对、内容检查和板厂预览见 [4.1](4.1-production-handoff.md)。来自当前文档的导出不自动成为制造候选；完成本次阶段后不擅自展开后续工作。
