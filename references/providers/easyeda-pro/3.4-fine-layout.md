# 3.4 1.5维重力算法

细布局需要实际板框：已有板框直接沿用；没有板框先创建并回读，再开始。粗布局继续使用原入口。

本入口从项目重力试排 v5 的两份脚本迁入，使用有限形状组块和重力下落生成候选。它实际计算新的摆放位置，辅助的[局部候选审阅](3.4-fine-review.md)用于比较焊盘距离和网络跨度。

## 算法

1. **组成块。** 从 `spatial.localGroups` 取成员；共享器件的组通过并集合并，形成不重复的移动单元。未分组器件和现场独立测试焊盘各自成块。每块保留成员的装配占位矩形集合，以此识别块内空隙。
2. **预生成形状。** 每块产生原状、沿 X 收拢、沿 Y 收拢、XY 收拢，再组合配置允许的 0/90/180/270° 整块旋转。收拢围绕组锚点，不交换成员相对次序；重复形状去重。固定块只保留原状，含独立测试焊盘的块不旋转。
3. **按原画面取块。** 依据原装配占位划水平层，从上到下取层，同层从左到右取块。这里指 EDA Y 向上的坐标：画面上方是较大 Y。
4. **尝试下落。** 对每个形状枚举板边、横向网格、原相对位置及已有块接触位置；沿 Y 向较小值下落，直到成员占位触及板框内边或已放块。碰撞按每个成员矩形判断，保留可容纳后续块的空隙。贴边器件另尝试对侧边缘落点。
5. **选落点并检查。** 优先降低已放部分最高点；相同时偏好较少变形/旋转，再按靠左、靠右、居中或原相对位置等策略打破平局。每放下一块就检查板内与无重叠；固定块和显式禁放区先作为障碍。
6. **输出多种装填。** 同一取块顺序跑配置的落点策略，保留每组结果、逐块顺序及完整形状库。优先完整装入，其次比较装入数量和使用高度。失败对象列为未放入，不能把部分装入当整板方案。

## 执行

```text
node <skill>/scripts/pcb-fine-layout.mjs --project-root <项目目录> --snapshot <snapshot.json> --report-dir <新的证据目录>
```

复用项目的 `PCB_LAYOUT_CONSTRAINTS.v1.json` 及其引用的局部组、器件特征、几何视图、装配规则和机械配置，不重新手抄坐标。可用 `--config` 指定另一份项目配置，`--options-file` 提供下列装填参数。

```json
{
  "marginMil": 5,
  "gridMil": 5,
  "edgeReserveMil": 200,
  "fixedRefs": [],
  "reservedRegions": [],
  "trials": [
    {"name": "left", "tieMode": "left"},
    {"name": "original", "tieMode": "original"},
    {"name": "center", "tieMode": "center"}
  ]
}
```

这些数值沿用原型的搜索默认值，不是板厂或装配要求。板边余量按装配占位计算。试验可设置 `edgeReserveWeight`、`edgeHeightWeight`，或显式 `forceHorizontalRefs`；通用脚本没有特定接口位号例外。旋转许可来自项目 `hard.preserveRotations`、`search.rotationDeltas`、`hard.allowedRotationDeltasByRef` 和器件特征的允许角度交集。

原生锁定、机械配置的 `lockedDesignators`、`hard.fixed` 和 `fixedRefs` 都会固定对应块；合并块内任一成员固定，则整块保持原样。若组内原始装配占位已相交，先报告输入问题，不能把该组当作合法形状。删除的测试点不会由旧 Contract 自动补回，当前快照中的对象才参与装填。

板框解码复用已有 Provider，当前支持唯一闭合矩形。若缺失板框，显式配置的尺寸可以生成 `board-outline-request.json`；用[板框入口](3.2-pcb-foundation.md#矩形板框可执行入口)创建并验证后读取新快照。没有尺寸时先确定机械要求。配置与原生板框不一致时报错。

输出为 `summary.json`、`runs.json`、`candidate.json`、`shape-library.json`、`geometry.json`、`candidate.svg` 和 `comparison.html`。网页可切换策略、逐块查看放置顺序和各块预生成形状。`inputs.json` 冻结本次所有输入。

## 验证与当前边界

落点检查继承原型的装配包围盒近似；完整候选另用共享模块重算装配规则及封装真实贴边条件。装配包围盒贴边不代表封装本体贴边，接触舍入也可能被更严格的检查报告；两类结果分别显示，不因此宣布整板通过。局部组、形状及下落算法与历史版本可以逐项比对。

当前入口只生成离线候选。后续应用须覆盖器件、位号、独立测试焊盘，核对原对象归属与网络，再保存和独立回读。旧项目的位号/测试点补写没有完整成功证据，因此没有把它搬成通用 apply，也不输出容易被误作完整应用的“仅器件计划”。

有铜线的快照仍可供假设装填预览；实际移动需要支持跟线移动或重布线的执行器，再检查受影响连接和 DRC。这是执行能力边界，不是禁止对已布线板做细布局。

本算法未实现任意柔性变形、成员交换、越过阻挡块进入封闭空腔或全局电气最优搜索；元件中心顺序、有限收拢形状和重力落点就是当前方法。功能块耦合、特定功率/采样关系、丝印、热和三维条件要在选定候选后继续检查。
