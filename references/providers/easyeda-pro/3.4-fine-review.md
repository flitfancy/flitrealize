# 3.4 细布局辅助：局部候选与关键连接比较

细布局开始前需要实际板框：已有板框就沿用；没有板框，先按机械尺寸创建并回读，再继续细布局。粗布局继续使用原有入口。

本入口整理了局部细化中反复使用的操作：保留当前布局和固定锚点、提出少量明确移动、按真实焊盘计算距离和网络跨度、检查候选新增或消除的问题。AI 决定要改善的电路关系与候选；脚本负责重复计算。当前支持显式候选比较，未实现自动搜索最优细布局。

## 输入与输出

读取当前 Provider 的 `snapshot.json`，包含器件、明确归属的焊盘、独立测试点、板框、Region、铜对象数量和 sourceHash。可复用同次 `pcb-layout.mjs --mode prepare` 的快照；准备诊断中若有 Contract 范围差异，须在对应写入前解决，不能凭本工具的几何结果忽略它。手工修改或创建板框后重新读取。

局部提案使用现有 `pcb-placement` 的 `placements`、`groups` 或 `scenarios` 格式，外面加审阅配置：

```json
{
  "schemaVersion": 1,
  "expectedSourceHash": 123456789,
  "movableDesignators": ["C_BYP"],
  "planInput": {
    "mode": "plan",
    "expectedProjectUuid": "<项目UUID>",
    "expectedDocumentUuid": "<PCB UUID>",
    "lockedDesignators": ["J_PWR"],
    "reservedRegions": [],
    "clearanceMil": 8,
    "scenarios": [
      {"name": "bypass_nearer", "placements": [{"designator": "C_BYP", "x": 250, "y": 300}]},
      {"name": "bypass_turn", "placements": [{"designator": "C_BYP", "x": 250, "y": 300, "rotation": 90}]}
    ]
  },
  "audit": {
    "nets": ["VDD", "GND"],
    "padPairs": [{"id": "vdd_bypass", "net": "VDD", "a": {"ref": "U_LOAD", "pad": "1"}, "b": {"ref": "C_BYP", "pad": "1"}}]
  }
}
```

数值是格式示例，实际位置由当前快照和电路要求决定。`movableDesignators` 是本次开放范围；其余器件保持原位。原生锁定及 `lockedDesignators` 仍有效。省略 `rotation` 保留当前角度；仅支持相对 90° 倍数的旋转。独立测试点保持原位，按现场保留数量参与检查，不补回已删对象。

`audit.nets` 省略时列出移动器件涉及的所有非空网络；显式提供时按完整指定清单计算。网络跨度使用焊盘中心的 HPWL，即 X 跨度加 Y 跨度；`padPairs` 指定准确物理焊盘号，默认欧氏距离，可用 `metric: "manhattan"`。有明确工程依据时加 `maxDistanceMil` 作为该对端点的硬上限。每项改善或退步单独展示，不用总跨度变短替代功率环路、反馈隔离或 Kelvin 拓扑检查。

运行：

```text
node <skill>/scripts/pcb-fine-review.mjs --snapshot <snapshot.json> --input-file <fine-input.json> --assembly-rules <PCB_ASSEMBLY_RULES.v1.json> --report-dir <项目内新的报告目录>
```

`--assembly-rules` 复用已有装配规则，可省略但报告明确标为未检查。脚本只读输入并生成本地报告，不连接 EDA。报告目录必须是新目录，避免覆盖旧证据。

输出包括 `review.json`、可读的 `review.md`、带基线/候选占位图的 `comparison.html`。通过本次检查的候选另有 `placement-plan-<name>.json`，供 `pcb-edit` 重新做现场 plan；它不是已绑定 EDA 指纹的 apply 请求。

## 板框

已有板框使用 Provider 的原生解码，不重新计算包络或替换原对象。当前支持唯一闭合、轴对齐矩形，复用已实现的固定板框检查；异形、多个轮廓或孔槽明确报不支持。

没有原生板框时不进入细布局评价。若 `planInput.boardBounds` 已提供明确机械尺寸，报告生成 `board-outline-request.json`；按[板框入口](3.2-pcb-foundation.md#矩形板框可执行入口)完成 plan → apply → verify → save，重新读取后再运行细布局。没有尺寸时先从项目机械要求确定，不用默认退距凭空生成。已有板框且另填 `boardBounds` 时两者必须一致。

## 如何使用审阅结果

1. 先看固定范围、板框和关键焊盘是否正确，再看逐网、逐对距离变化。每个候选列出全部几何问题、相对基线新增的问题和已消除的问题；原有问题不会被隐藏。
2. 复核电源去耦、开关回路、采样取点、接口操作面、散热和项目已有约束。当前审阅使用二维器件/焊盘包围盒和可选装配边界，未自动载入粗布局的全部接口/功能块规则；丝印、三维和电气拓扑仍需单独检查。
3. 选定候选后，重新读取当前 PCB；sourceHash 改变则对新快照重跑审阅。再将该次导出的提案交给[现有 `pcb-edit` 流程](3.4-pcb-placement.md#明确移动与空白分析)，由它重新读取、plan、apply、verify、save、保存后回读。实际焊盘与关键距离按同一审阅清单复核。
4. 同步同一份 `CURRENT_HANDOFF.md` 的布局正文和顶部状态，分别说明提案、实际写入、保存与未检查范围。

已有铜线不是细布局的通用禁令。本入口仍可计算假设移动的指标；当前 `pcb-placement` 执行器不能带动或重布导线，因此有铜对象且候选移动器件时不导出可执行提案。实际移动须换用具有该能力的入口，并验证受影响连接、参考回流和 DRC；不能通过删铜或清理状态绕过这一能力缺口。

## 从项目旧脚本提取的内容

保留的通用能力为：明确固定锚点、局部组平移、保留或调整器件旋转、按归属变换焊盘、逐网 HPWL 和指定焊盘对距离比较。它们复用现有几何、板框、装配和 EDA 写入模块。

旧项目中的器件名、坐标、网络清单和三轮细化记录留在原项目。本页仅作距离和几何审阅辅助；形状预生成及重力下落的细布局主入口见[1.5维重力算法](3.4-fine-layout.md)。
