# 3.5.1 粗布局：安排块

粗布局安排块，细布局安排簇和器件，走线连接并反馈。块是承担一项功能的部分；簇是块内的小块，由联系紧密的器件组成。

需要安排块的位置、朝向、占用空间和块间连接通道时读取。拿到 [布局准备](3.1-pcb-review.md#布局准备)交出的“粗布局可用输入”，形成整体安排，再交给细布局处理块内簇与器件。

## 粗布局原则

粗布局先安排块，输出可比较的摆放图和空间分配。器件的大致位置用于检查块能否容纳、连接是否顺畅，不在本阶段锁死块内全部器件。按已有电路、封装、网络和项目要求整理以下五条摆放倾向：

1. **功能关系：**联系紧密的器件或功能块尽量靠近，保留已确认的关键邻接关系。
2. **空间留白：**引脚密、连接多、需要粗线的地方适当宽松，尤其照顾连接集中的一侧。
3. **器件朝向：**主要连接端朝向相关器件，减少明显折返和交叉；旋转遵守已有机械方向与许可姿态。
4. **无源器件：**普通A–GND支路在允许就近接地的条件下优先照顾A端；B–C兼顾两端，再按用途决定靠近哪端。已有去耦、功率或敏感回路要求继续保留。
5. **整板关系：**调整一个器件或块时，同时看其他块的大致连接是否更顺，兼顾整体疏密和留白。

这些原则主要形成粗布局偏好，沿用板框、固定件、禁区、装配下限和已确认电气条件。此阶段安排块的占位与通道预留；逐脚出口、具体铜路径和孔位留给后续细化，粗布局不以完成实际走线为条件。

功能区大致确定后，区域内重排及其关键电气、跨块连接和位号验收按 [3.5.2 细布局](3.5.2-fine-layout.md)。开放功能块结果仍须检查现场区域与外部环境。

## 量化与现有脚本的衔接

可以把五条原则逐步表达为分组、关联权重、留白等级和朝向偏好，再比较候选。具体间距和权重由项目确定，不因“引脚密”或“连接多”就新增统一毫米硬门槛。

| 原则 | 可量化的方向 | 现有支持与待补范围 |
| --- | --- | --- |
| 功能关系 | 语义分组、关联强弱、相关连接距离与节点跨度 | 已有语义转换和连接代理；组归属本身不生成距离硬上限 |
| 空间留白 | 留白等级、期望疏密、主要连接侧的空间偏好 | CP-SAT可选粗网格疏密与连接侧软留白：按真实有效连接分侧，留白随器件旋转；具体等级由项目提供 |
| 器件朝向 | 在许可旋转中比较主要连接方向和距离 | 已有许可旋转、端点距离和接口外向条件；一般朝向软偏好尚未独立计分 |
| 无源器件 | 按用途确定两端的布局牵引优先级 | 已有明确端点关系与共享网络的跨度配置；普通A/GND或B/C优先级尚未按器件用途自动分配 |
| 整板关系 | 同时比较全板连接与间距分项，记录局部调整的其他影响 | 已有全板代理评分与候选报告，可配合摆放图审阅 |

量化只把摆放倾向接入布局模型。共享GND不按整板地焊盘两两吸引，已声明的关键地关系仍保留；无源件的功能也不能只由两端网络名决定。当前分组、权重与几何观察的字段和覆盖范围见[布局输入](technical/pcb-layout-inputs.md)。尚未接入的偏好保留为工程意图，不假定写入文字后就已参与求解。

## 交给细布局什么

依据粗布局可用输入，核对当前块的用途、成员与块间连接，安排块的区域、主要方向、占用空间和通道预留，再交出“粗布局结果”。通道预留说明需要留出的位置与用途，尚未证明实际铜路径可布通。粗布局不要求把簇内每个器件排完。

| 交接内容 | 要说明什么 |
| --- | --- |
| 当前版本 | PCB 或候选身份、来源指纹、保存与核对状态；离线候选标明尚未写入 |
| 块的安排 | 沿用 Contract 的块名和成员，说明大致区域、位置、朝向、占用空间及分配依据 |
| 块内线索 | 已明确的簇、成员和关键关系；尚未分簇的部分保留待整理，不虚构新配置字段 |
| 跨块环境 | 实际连接端点、主要连接方向、通道预留、机械锚点和障碍；记录尚未完成的路径验证 |
| 细布局范围 | 选中的块、固定件、可移动或可转器件、允许让位的邻居及其范围 |
| 当前结论 | 已验候选、空间不足、规则冲突和未覆盖项，分别给出证据 |

交接复用项目记录与派生报告，不另填网表或坐标。现有语义求解以器件为变量，功能组提供柔性偏好，归属本身不生成区域硬约束；`groups` 和独立开放块结果不会自动分配现场区域。块区域自动分配及可直接交给细布局的通用区域产物仍待实现；已有细布局入口接受明确成员、区域和外部环境，不能把两者笼统写成“交接都未实现”。

## 按需检查通道

先按块间主要连接看通道是否被占、朝向是否合适、连接集中的一侧是否留白。需要进一步比较时，用已有工具对明确端点做有限路径诊断，或估算[潜在地空间](3.3-ground-space.md)；命令和输入见[预走线技术参考](technical/pcb-prerouting.md)。通道预留仍不是实际铜路径保证。

粗布局不要求每个候选整板走通。诊断发现块间空间或方向问题时，反馈相关块与阻挡证据，再在本轮许可范围比较；逐脚出口竞争和关键网试走留给细布局，不自动移器件。

## 当前能力与入口

现有准备、语义转换、搜索和 CP-SAT（约束求解器）、位号模板、公共几何验收可以复用。粗网格疏密和连接侧留白是可选软目标；是否布通、回流或电气性能合格仍需后续检查。

独立开放块、带铜模板和未含位号的候选尚不具备完整原生写入计划，不能直接应用。

## 入口

选择后端时读 [布局输入与求解参考](technical/pcb-layout-inputs.md#布局求解入口与后端)，核对输入、命令和支持边界；其中维护语义与冷启动、开放块、带铜模板、最小样例及兼容说明。连接 EasyEDA 或写回前再读 [布局与空间](providers/easyeda-pro/3.5-pcb-placement.md)。

## 验收与停止

所选块的区域、占用边界、固定要求、主要连接方向和细布局范围明确，本轮身份与块占位核验满足已有约束后，可以进入细布局。块内簇与器件的细排、逐脚出口和通道试走线留给后续；未验的通道和电气条件保持待验。选定块的安排不等于固定其全部内部器件，也不等于实际走线完成。

获得满足本轮要求的候选后停止。预算耗尽、连续尝试无有效改善、区域不足或规则冲突时也停止，交出最佳已验候选或具体阻塞原因，再明确下一轮范围。稳定结果按 [项目主文稿](0.1-continuation.md)同步。
