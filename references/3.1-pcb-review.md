# 3.1 PCB 设计与检查

把原理图电气意图落实成实际 PCB。整体设计或跨阶段检查读本页；已有项目的局部工作从相关章节和本次操作说明进入。

## 实际 PCB 布局顺序

转 PCB 并核对 → 布局准备 → 粗布局安排块 → 细布局安排簇和器件 → 走线连接并反馈 → 整板检查 → 制造交接。

| 工作 | 交出什么 | 详细说明 |
| --- | --- | --- |
| 转 PCB 并核对 | 对应原理图的 PCB 基线、核对结果与未决项 | [转换与核对](#从原理图转-pcb-并核对) |
| 布局准备 | 块及连接、板框、固定范围、禁区和预留等粗布局输入 | [准备](#布局准备) |
| 粗布局 | 块的位置、朝向、占用空间、通道预留和细布局范围 | [3.5.1](3.5.1-block-layout.md) |
| 细布局 | 簇与器件候选、逐项验收、按需试走线及实际写入状态 | [3.5.2](3.5.2-fine-layout.md) |
| 走线与反馈 | 实际路径或候选、检查结果和最小调整范围 | [走线与局部反馈](#走线与局部反馈)、[3.8](3.8-prerouting.md) |
| 整板检查 | 当前源版本、完整网络和关键电气／机械检查、遗留限制 | [完成条件](#完成本阶段) |
| 制造交接 | 已保存源文件与本次检查依据 | [4.1](4.1-production-handoff.md) |

## 从原理图转 PCB 并核对

拿到当前原理图、Contract、封装映射，以及保存和连接检查结果。仅新建、单页来源使用[新建 PCB 入口](providers/easyeda-pro/3.1-pcb-create.md)；已有 PCB 更新使用已验证的方法，并保留范围外内容和期间的用户修改。

转换或更新后读取实际 PCB，核对本次器件范围和身份、封装、引脚到焊盘映射、焊盘归属及网络。原理图专用、有意延后或 PCB 新增对象分别说明，同时记录目标身份、锁定、已有铜与保存状态。

影响布局的身份、映射或连接差异先处理，其余未决项说明影响。交出“PCB 基线、核对结果和未决项”：基线是本次实际 PCB、来源版本与保存状态，核对结果说明与上游的对应关系。纯核对不附带转换或保存；实际写入与恢复按 [0.3](0.3-easyeda-pro.md#现场边界与验证)。

## 布局准备

汇总本轮块名、用途、成员、块间连接和电源树，以及板框、固定接口、机械锚点、安装孔、禁区与预留用途。结合封装、重要网络、外壳／高度条件、测试和调试访问，形成粗布局可用输入。

必须检查并按既定规则设置网络配色，已有正确配色保留；用途、分类、保存回读、显示确认及无法执行时的处理只在[配色顺序](providers/easyeda-pro/3.4-pcb-net-color.md#布局前的配色顺序)维护。只读或离线任务记录未完成部分，不因流程顺序附带 EDA 写入。

### 机械与层叠的前置条件

本轮不能改变的孔、接口、外壳开口和机械方向先明确，预留空间注明用途。板框或机械条件仍可在允许范围内收敛，但暂定值须有依据和变化范围；不能把未知当作无约束，也不为求解暗改固定件。

层数、层用途和重要网络参考层结合布线密度、电流、散热、高速／敏感信号、板厚、制造能力与成本选择。物理介质、铜厚及阻抗依据来自板厂能力或明确假设。会影响本轮几何或路径的条件在求解前确定，变化后刷新相关输入；后续可收敛项保留影响说明。

脚本求解前复用输入准备完成身份关联和规则检查，字段与覆盖范围见[布局输入参考](technical/pcb-layout-inputs.md)。身份、映射和规则冲突先解决；当前可修复间距问题可作为起点。只有缺口阻止当前工作或可能推翻关键器件、封装、接口和板框时才回上游。

## 粗布局与细布局衔接

粗布局先安排块，保留块内器件继续调整的空间；完整交接与验收见[粗布局](3.5.1-block-layout.md)。细布局在明确区域和成员范围内安排簇与器件，保留外部环境，逐项检查关键关系和位号，见[细布局](3.5.2-fine-layout.md)。

细布局入口已经衔接求解、位号、验收、试走线、应用、续存与只读复核。粗布局的块区域自动分配和可直接交给细布局的通用区域产物仍待实现，需要明确本轮区域与成员；走线失败后自动选择并移动器件的闭环也未实现。

## 局部调整引脚

当前引脚造成明显交叉、绕行或拥挤时，按[引脚调整](2.1-schematic-contract.md#引脚调整)核对功能复用、电气与固件条件。决定变化后同步 Contract、实际原理图、映射和受影响接口，再继续正式布线。

## 走线与局部反馈

拿到同一版本的布局、实际网络、层与规则，按关键电源／返回路径、功率环路、高速接口、敏感采样和保护等风险安排顺序。制造最小尺寸是下限，线宽、间距和孔要求仍依据电流、电压、压降、温升、长度、参考和实际铜厚确定；高电流路径检查最窄位置及缩颈长度。

规则、指定改宽和现场布线分别见[3.6](providers/easyeda-pro/3.6-pcb-routing-plan.md)、[3.7](providers/easyeda-pro/3.7-pcb-trace-width.md)及[3.8 走线](3.8-prerouting.md)。按需试走线与地空间估算用于比较候选，不能要求每个布局候选整板走通，也不代替实际铜验收。

失败报告网络、端点、出口／通道及已知阻挡对象，交给对应粗或细布局明确最小调整范围。有限搜索失败、预算耗尽、规则冲突与能力不支持分别记录，不自动扩大移动范围或清空整板。候选变更后重新绑定输入与规则。

## 地、平面和铺铜

布局时可按需估算[潜在地空间](3.3-ground-space.md)。正式走线后检查实际参考铜、去耦与功率回路、ESD 泄放、换层回流、孤岛和狭窄通道，以及开槽／keepout 的影响。分区要说明电流和跨区信号怎样返回；地孔数量不作为独立目标。

实际层、板框、keepout 与铺铜见[3.2](providers/easyeda-pro/3.2-pcb-foundation.md)，回流和接地见[3.3](providers/easyeda-pro/3.3-pcb-grounding.md)。重铺并核对实际铜后，再完成本次回流与整板检查。

## 热和机械

核对功率器件铜面积、热孔与散热焊盘，发热对周围器件、气流及外壳的影响。检查器件高度、装配方向、连接器插拔、螺丝／支柱受力，以及返修、探针、声孔、光路和天线空间。空白可以承担这些用途，不为填满板面取消预留。

## 更新项目主文稿

按[0.1](0.1-continuation.md#pcb-主题与面板对应)更新本次布局和网络规则主题，保留块名、成员、关键尺寸、固定条件、理由及来源。实际几何、规则配置和详细报告仍由原制品保存；正文说明当前布局、布线、铺铜、保存和检查范围，不复制坐标或网表。

## 完成本阶段

进入制造准备前确认：

- PCB 已保存；器件、板框、孔和接口位置正确，必要引脚调整已同步。
- 所需网络已布通；关键拓扑、支路、换层、参考回流、噪声耦合、过孔和缩颈满足当前设计。
- 实际铺铜已更新，DRC 没有未解释的当前问题。
- 机械、装配、访问、测试和散热已完成本次检查。
- 对应主文稿、证据入口、已接受限制与当前交接已更新。

交给[4.1 制造准备](4.1-production-handoff.md)的是同一版本的源文件与检查依据；局部候选或代理指标通过不能独立证明整板可制造。
