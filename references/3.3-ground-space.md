# 3.3 潜在地空间与参考层诊断

在真正铺地铜前，按当前摆放和候选走线估算还剩多少空间、哪些区域被切开、关键地焊盘能否在模型中接到选定主区域。用它比较候选和提前发现窄通道，帮助决定是否需要调整布局或走线。

## 拿到什么

使用同一版本的板边、焊盘、已有或候选铜、过孔、层与禁区，并给出本轮地网络、间距和搜索条件。候选替换旧铜还是增量增加要明确，不能把同一铜重复算入。

粗布局按需检查块间留白与潜在参考空间，细布局按需检查局部出口和关键关系。何时使用见[粗布局](3.5.1-block-layout.md#按需检查通道)与[细布局](3.5.2-fine-layout.md#局部重排与反馈)，普通候选不必每次做完整地空间分析。

## 做什么、交出什么

工具从已声明的障碍估算两层可用于铺铜的区域，观察区域分割、宽窄、关键地焊盘的潜在可达性及可放连接孔的位置。交出可比较的空间诊断，条件允许时附模型内连接孔候选。

比较时同时看关键地端点、空间分割、孔位和相关线长变化。更少的孔不能抵消关键地空间退步；搜索范围不足、缺项和未覆盖条件保留在报告。字段、参数、命令与原始输出见[地空间技术接口](technical/pcb-prerouting.md#地空间估算的技术接口)。

## 能说明到哪

空间可达只表示当前模型中有潜在连接，工具不创建地铜、不证明实际地连通，也不完成回流、载流或热验证。估算使用声明的二维几何与孔规则，未自动纳入机械槽、天线镂空、任意局部地线、制造认可的焊盘内热孔或原生热焊铜形状。

模型不可达不直接等于实际 PCB 断路，有限采样无路也不证明物理无解。选中候选后仍须按[铺铜](providers/easyeda-pro/3.2-pcb-foundation.md)和[接地](providers/easyeda-pro/3.3-pcb-grounding.md)核对实际铜与对应回流。
