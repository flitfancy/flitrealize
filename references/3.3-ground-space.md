# 3.3 潜在地空间与参考层诊断

预走线或布局候选需要比较地出口、区域分割、换层槽位或参考层占用时读取。它是已有 [3.3 接地](providers/easyeda-pro/3.3-pcb-grounding.md)的前置估算；实际铺铜读取及写回继续使用原接地/铺铜入口。

数值运行依赖按需见[首跑指南](../docs/first-run.md#数值与路由环境)。

```text
node <skill>/scripts/pcb-preroute.mjs --project-root <项目> --input <冻结输入JSON> --candidate <候选铜JSON> --mode ground --python <解释器>
```

候选默认替换输入铜；增量方式须在请求中声明 `candidateMode:"additions"`，不将铜重复叠加。地网络、格点、整像素收缩、区域面积阈值、核心宽度、换层槽位搜索半径及孔规则均可配置；参数及来源随报告保存。

## 模型含义

从当前候选焊盘、铜线、孔、板边和显式keepout得到两层潜在铺铜空间。原生矩形/椭圆接触形状关联地焊盘，区域图考虑声明的跨层焊盘及可放地孔位置。以输入选择的主区域检查潜在可达性；全图可达时可在限定区域图上选择连孔。

输出 `ground-space.json`、`ground-link-plan.json` 和可选采样数组。面积、分割区、核心宽度与相邻孔槽位用于比较候选；它们不证明地已经铺好、载流/热/回流已经通过。孔槽位搜索半径是诊断范围，不是新的功能块距离硬上限。

模型不包含未声明的机械槽、天线镂空、任意局部地线、制造认可的焊盘内热孔及原生铺铜热焊形状。不能把不可达端点直接叫作实际PCB断路，或将有限采样无路宣称为物理无解。新增候选应至少保留关键地端点的模型状态，并在真实候选副本上验证实际铜。

地和参考层改善、过孔减少、线长和层占用分别记录。更少孔造成关键地空间退步时保留对照，不单独按孔数接受。输出始终标明 `groundCopperCreated:false`、`groundConnectivityVerified:false`、`nativeWrites:0`。
